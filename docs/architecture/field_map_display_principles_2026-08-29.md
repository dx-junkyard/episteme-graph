## 1. 分野マップの目的（表示判断の基準）

1. **見当識**: いま学んでいることが分野全体のどこかを掴む（学習者）。
2. **弁別**: 考え方・切り口の異なるものを区別し、似たものを束ねる。
   「同じ主題だが方法が違う」「触れているだけか、主軸か」。
3. **キュレーション**: コーパスの厚み・薄み・欠けを見て次の取り込みと地図の成長を
   判断する（教員）。

反目的（確立済みの不変条項）: 数値評価にしない / 地図は正解でなく投影 /
AI は候補まで / 煽らない・静かであること。

## 2. 表示原則（①′〜⑤）

- **原則①′ 地形は人間・関係は離散の辺**: 共有地図の**地形**（region / concept の
  位置）は人間が描き、凍結版の間で不変とする。**関係は自由に可視化してよい** —
  ただし必ず離散の辺として、名前（kind / 由来）・出所（教員確定 / AI推定）・
  推定なら骨格版を付けて描く。埋め込み由来の関係が共有地図の**恒久配線**になる経路は
  candidate → 教員確定 → 凍結のみ。局所・使い捨てビュー（近傍ビュー・レーダー・
  旅カード等）の自動レイアウトは自由だが、意味を持たせる軸には宣言された名前を
  与える（前例: 「いまここの周り」の縦=依存の向き）。
  **禁じるもの**: ①地形を埋め込みで動かすこと（散布図・UMAP 型 — 軸が無意味・
  配置が不安定・切り口の混同をそのまま可視化する）②ラベルのない近接を主張として
  使うこと。
- **原則② 論文は座標ではなく係留**: 論文は地図上の1点を持たず、「名前を持つ
  アンカーへの複数の接続」として描く。論文が主役の場所はアンカーの中（クリック後の
  リスト）であって地図の上ではない。
- **原則③ 係留は〈出所・切り口・深さ〉の3修飾・すべて段階ラベル**: 出所
  （AI推定/教員確認）・切り口（perspective 6語彙）・深さ（触れている/使っている/主軸 —
  係留プロファイル構想、未実装）。数値は出さない。
- **原則④ 集約は塗り・欠けは事実文**: 領域の集約は密度ビンの塗りのみ（CR3 裁定
  踏襲）。深さの組成のような質的情報は色チャネルを増やさず事実文で出す
  （「主軸とする論文がまだありません」）。地図は視覚的に静かに保つ。
- **原則⑤ 差分・比較は地図の外の並置事実文・未測定はキーごと消す**: 「何が違うか」
  は空間で描けば嘘になる。compare 2区画・チップの並置形式が正。測れないものは
  ラベルなし・キーなし。

## 3. 利用シーン別の適切な表示

| シーン | 表示 | 根拠 |
|---|---|---|
| 学習中の「いまここ」 | 現行のまま。情報を足さない | 静かな見当識。注意の税を課さない |
| コーパス回遊（論文の海） | 地図は現行。アンカークリック後の論文リストに深さ・切り口ラベル（未実装・係留プロファイル待ち） | 選書に効くのは主軸か言及かの区別 |
| 配置レビュー・ギャップ・辺候補（教員） | リスト型キュー + 出所チップ + 構造関与の証拠1行 | 教員の1クリックの裁定価値の最大化 |
| コーパス棚卸し（教員） | 領域ごとの深さ組成の事実文（未実装） | 件数密度が隠す質の薄みの開示 |
| 取り込み前探索（discovery/radar） | 着地1行・重なり/新しい面チップ・compare 並置（実装済み）+ 深さ差分行（未実装） | 新しい切り口か重複かの判断材料 |
| 関係の把握（学習者・教員） | 凍結骨格の辺（恒久配線）+ 推定の糸レイヤー（点線・出所ラベル・既定オフ・トグル） | 原則①′。inferred 配置を出所ラベル付きで見せる既存哲学の辺への適用 |

## 4. 原則①の改訂経緯（記録）

初版の原則①「地理は人間が描いた骨格だけ。埋め込みから配置を自動生成しない」に
対し、オーナーから「配置・配線で関係性を見せることはできる。位置に厳密な意味は
なくても関係は表現できる」との指摘。検討の結果、初版は**連続的な位置**（監査不能な
主張）と**離散的な配線**（名前と出所を付けられる主張）を混同していたと判定し、
①′ に改訂。改訂から直ちに導かれた実装が2つ:

- **(a) 辺候補のレビューキュー**: プロトタイプ近傍 + 配置共起 → candidate →
  教員確定（kind 選択）→ 凍結配線。カテゴリギャップ候補（ノード追加）の辺版。
- **(b) 推定の糸レイヤー**: 確定前の推定関係を点線 + 出所ラベル + 骨格版明示で
  重ねる読み時導出のトグルレイヤー（既定オフ）。

設計の正本は [atlas_relation_edges_design.md](../features/atlas_relation_edges_design.md)。

## 5. 採らない表示（恒久却下の記録）

- 埋め込みの2D散布図 / UMAP 配置（理由は①′）
- レーダーチャート型のプロファイル表示（連続値の軸 = 数値非表示の破り。
  ソート済み段階ラベルリストで代替）
- 論文間類似のネットワーク図（学習者向け。ヘアボール化・数値読みの誘惑。
  「近い論文」はレーダーのリスト形式が正）
- コーパスに応じた領域の伸縮・移動（地形の安定は見当識の前提）
