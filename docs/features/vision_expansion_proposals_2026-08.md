## §1 手法

7名の専門家ペルソナ（AI エージェント）による2ラウンド討論:

| ペルソナ | 専門・立場 |
|---|---|
| 学習科学者（教育学） | 自己調整学習（Zimmerman SRL）・knowledge in pieces（diSessa）・転移研究（Perkins & Salomon） |
| 脳科学・認知科学者 | 記憶固定化・スキーマ形成（SLIMM）・予測符号化・睡眠と学習。「理解＝予測モデルの更新」 |
| 宇宙物理学者 | 現役研究者・院生指導多数。「式変形は追えるが物理が見えない」学生を見てきたドメインユーザー代表 |
| 人類史・科学史家 | 知識の系譜・パラダイム転換・印刷革命。「このシステムが100年後に何を残すか」を問う |
| 科学哲学者・認識論者 | 反証と厳格テスト（Popper/Mayo）・証言の認識論・ピア不一致・分散認知 |
| ネットワーク科学・複雑系研究者 | パーコレーション・ネットワークモチーフ・集合知ダイナミクス |
| 学習体験デザイナー（HCI・ゲームデザイン） | 探索型ゲームの地図と霧・非同期マルチプレイの「他者の気配」・desire paths |

- **第1ラウンド（発散）**: 各自が `knowledge_network_vision.md` と CLAUDE.md（全層の構成）を読み、
  自分の専門知から独立に 3〜4 案を提案（計 28 案）。→ 付録A
- **第2ラウンド（討論）**: 全案プールを共有し、各自が支持（強化案付き）・懸念（専門的根拠付き）・
  結合提案を提出（支持 21 件・懸念 17 件・結合案 12 件）。→ 付録B
- **統合**: 討論で現れた「独立発見の収束」を軸に、主宰（Claude）が §3 の6提案へ統合。

全員に本システムの設計哲学（数値非表示・AI は候補のみ・情報を落とさない・監視しない・
全体の完成形は無い・リンクであってマージではない）を前提として与えた。

## §2 収束点 — 独立発見の一致

討論の最大の成果は、**異なる分野が別々の理論から同じ設計構造に到達した収束**が3箇所で
起きたことである。独立収束は実装価値の強い証拠として扱う。

1. **「開示の前に学習者自身の産出を挟む」文法（ELICIT-first）** — 4分野が独立提案:
   脳科学者（予測誤差が海馬の符号化をゲートする）／宇宙物理学者（研究者は式(2.8)を自分で
   導いてから紙面と照合する）／学習体験デザイナー（世界樹の迷宮の「地図を描かせる」）／
   学習科学者（pretesting effect・generative learning）。→ 提案1
2. **「セッションの縁と間」が設計されていないという診断** — 3分野が独立提案:
   学習科学者（SRL の forethought 相の欠落）／脳科学者（睡眠依存の記憶統合はセッション間に
   起きるのに誰も設計していない）／学習体験デザイナー（出発と帰還の額縁がないとエピソード
   記憶が作られない）。→ 提案2
3. **「同一パーツの通時的な伝記」** — 2分野がほぼ同型の提案:
   宇宙物理学者（式の伝記: TOV 方程式の60年）／科学史家（概念の伝記: 意味変容の一次史料化）。
   双方が相手の案を「独立発見の収束＝必然性の証拠」と明言。→ 提案4

また、討論は**同一の罠を複数分野が別の言葉で指摘する「収束する懸念」**も生んだ
（情報カスケード／誤同一視の爆風半径／閉世界の誤謬。各提案の条件節と §4 に反映）。

## §3 統合提案

### 提案1: 予測ファースト読解 — 「開ける前に自分が描く」三スケールの統一文法

**horizon: near〜mid ／ 収束点1に立脚**

R層の ELICIT→DIFF→REVEAL→SELF-CHECK 意味論を共通基盤に、「開示の前に学習者の産出を挟む」
を三つのズームレベルで同じ作法・同じ仮説文体で提供する:

- **式スケール（支配項の直感道場）**: derivation_chain の近似 operation
  （linearize_*/approximate_*/eliminate_*）**だけ**に「あなたならどの操作でこの式に向かうか」
  「r→∞ の極限で生き残る項はどれか」の予測を挟む。答えキーは A層の operation 構造から
  非LLM・決定論生成。恒等変形には挟まない（宇宙物理: 「判断が分岐する地点」のみ）。
- **論文スケール**: アブストラクトから「この論文が示さねばならない主張の骨格」を予想 →
  paper_skeleton / thesis_reconstruction artifact が答えキー。
- **地図スケール（白地図の測量士）**: atlas 骨格を開示する前に、学習者がそこにあると予想する
  概念とつながりを白地図にスケッチ（任意・スキップ可）→ 凍結骨格と構造照合（非LLM）。
  予想図は消えず個人層に永続（P4）。

**結合価値**: 仮説文体の DIFF・出典リビール＝権威・伏せフィールド非漏洩・数値非表示という
難しい作法を一度だけ作り三粒度が継承する。粒度を跨いだ往復（地図の外れ→論文の予測課題→
式の予測）が研究者の多重解像度の読みを一つの操作文法で貫通し、「このシステムでは開ける前に
まず自分が予測する」が機能ではなく文化になる。

**討論で付いた必須条件**:
- **opt-in の「精読モード」にする**（科学史家: 読書実践は歴史的に複数形。通覧 survey reading
  に摩擦税をかける単一の読書規律の強制は、歴史上例外なく探究の幅を狭めた。既定レンダリングは
  変えない）。学習体験デザイナー: 自分で選んだ縛りは没入を生み、押し付けられた縛りは離脱を生む。
- 予測は間隔を空けて出す（学習科学者: 毎回出すと機械的クリックに劣化し pretesting 効果は消える。
  desirable difficulty の維持）。
- モーダルなクイズにせず「霧が薄くかかっていてワンタップ予測で晴れる」連続的インタラクション
  （HCI: 予測を「中断」として体験させたら死ぬ）。
- リビール直後に任意の一行自己説明（「なぜ予測とずれたと思うか」）→ articulated trace へ
  （学習科学者: 自己説明効果は予測誤差の直後で最大化）。
- 対比ペア出題（Schwartz & Bransford の contrasting cases: 銀河スケール vs 中性子星表面で
  「同じ式・違う支配項」を並置してからリビール）。複数論文の近似 operation を持つ本システム
  だけが対比ペアを決定論生成できる。
- 予測の選択肢に「著者が実際に選ばなかった道」を混ぜる（宇宙物理: リビール時に「なぜ著者は
  こちらを選んだか」という研究者の視点が立ち上がる）。
- 外れた予測の痕跡は candidate・本人確定のみ（P1）。大胆な予測を萎縮させない。

**基盤**: R層 reconstruction_items（elicit_mode 族の拡張）+ derivation_chain / theory_claims /
thesis artifact（答えキー）+ atlas 凍結骨格 + interest_traces。判定はすべて非LLM・決定論。

### 提案2: 一晩の航海 — セッション境界を跨ぐ自己調整ループ

**horizon: near（migration ほぼ不要）／ 収束点2に立脚**

三案（問いの持ち越し／眠りに持ち込む問い／測量遠征）を単一の物語構造に統合する:

1. **出発**: 学習者が問いを一つ自分の言葉で立てる（旗＝articulated 痕跡として即記録・LLM非関与）。
   structure_anchor があれば地図・教材上の位置に旗として刺す（HCI: 空間に係留された意図は
   リストより再訪時の想起が強い）。
2. **滞在**: 確定痕跡（問い・引っかかり・connect した橋）が航跡として非LLM で束なる。
3. **着地（焚き火）**: 既存 reflection（「今日の理解を自分の言葉で」）+ 遠征中に立った問いから
   一つを「寝かせる問い」として選ぶ（新規入力ではなく選択なので認知コスト増ゼロ）。
4. **セッション間**: **システムは何もしない**。督促ゼロ。この沈黙自体が設計であり、睡眠中の
   リプレイと系統統合に処理を委ねる（脳科学: 学習アプリの最大の盲点はセッション間の時間）。
5. **再訪**: 開幕画面で旗が待っている。問いだけを先に見せ「いまのあなたならどう答えますか」の
   一手再予測（任意）→ その直後にだけ「帰り道の景色」の再訪差分（「前回のあなたの近傍には、
   この橋はまだ架かっていませんでした」）を風景差として重ねる。

**結合価値**: Zimmerman の三相循環（forethought→performance→self-reflection）が UI 上で初めて
閉じる（各提案単独では一相ずつしか埋まらない）。着地・開幕という同一の一等地を三機能が
奪い合う UI 渋滞を、旅の出発と帰還という単一の物語構造が解消する。符号化→オフライン統合→
再固定化という記憶の一晩のサイクルに、体験の額縁が正確に重なる。

**条件**: 未消化バッジ・連続日数・忘却曲線数値なし。成功/失敗の判定なし — 未解決のまま帰還した
遠征も同格の記録（P4）。全工程が非LLM・本人のみ可視。intention と「寝かせた問い」は同一の
痕跡語彙で実装し二機能を別々に作らない。

**基盤**: discuss opening/landing（各一枠追加）+ interest_traces（kind 追加のみ）+
personal graph の毎回導出 + atlas-cues の抑制ルール。

### 提案3: 賭け金の台帳（Stakes Ledger）— 修論テーマは疑いの地図から生まれる

**horizon: mid〜moonshot ／ D層を記帳装置から研究前線の航法装置へ**

四つの部品の結合で、Mayo の厳格テスト理論が要求する完全形 —「失敗し得る条件が明文で、
失敗の帰結が追跡可能で、まだ実行されていない厳格なテスト」— が一つの台帳として立ち上がる:

- **反証条件レジストリ**（哲学者）: verification_scopes（どこで確かめられたか）の論理的双対
  「どんな観測・測定結果が出たら覆るか」を claim 単位で記帳。AI が導出グラフの下流到達集合 +
  条件文生成で candidate を出し、教員が確定（D2-4 と同型）。反証条件が書けない主張は
  「反証不可能」なのか「未検討」なのかが初めて区別可能になる — 空欄はここでも発見。
- **到達可能性の区分**（宇宙物理の強化案）: 反証条件に reachable / next-generation /
  unreachable を教員が付与。到達可能な反証条件は検証提案（D3-2）に直結し「修論テーマの晴れ間」
  になる。到達不能しか書けない主張は「当面プログラム的に受け入れられている前提」という
  科学社会学的な読み方を学生に教える。
- **観測の反実仮想**（宇宙物理）: 前提でなく観測系 claim（MEASURES / diagnostic_application）を
  仮に倒し、既存 counterfactual 伝播で collapsed/surviving/indeterminate を流す。「H0 の測定が
  2σ ずれていたらこの結論のどこまで生き残るか」。哲学者の強化: 倒す対象を「観測値そのもの」と
  「systematics という補助仮説」で区別記帳（Duhem 問題の体験化）。
- **独立支持経路の台帳**（ネットワーク科学）: Menger の定理で結論ノードへのエッジ非交差経路数
  ＝独立な支持線の数、最小カット＝「同時に倒れると結論が切断される観測の最小集合」を決定論
  計算。学習者には数値でなく段階事実文（「単一の支持線に立っています」「複数の独立した観測に
  支えられています」）。距離梯子（セファイド較正→超新星→H0）のような「分野の賭けの構造」が
  初めて教材になり、H0 tension 型の論争を読む構造的視力が育つ。

**討論で付いた必須条件（閉世界の誤謬 — 哲学者・ネットワーク科学者が独立指摘）**:
- verification_scopes の補集合は「分野の誰も検証していない」ではなく「**このコーパス内に検証
  記録がない**」でしかない。コーパスは高々数十〜数百論文であり、見かけの穴の大半はコーパスの
  穴。晴れ間の事実文を indexed な語り（「このコーパスの中では検証記録がありません」）に
  **語彙レベルで固定**し、分野レベルの不在を主張する語彙を構造的に禁止する。
- verification_proposal への昇格前に「コーパス外文献の確認」を必須ステップとして挟む。
  標準化判定と同型の三角測量（LLM 事前知識への照会 + L層凍結版 + コーパス反復）も候補化の
  前提にする。晴れ間は発見の候補地であって発見ではない。
- 煽り語彙禁止（D層ガードレール踏襲）・egocentric な旅としてのみ提示（KN-1）・研究価値の判断は
  師弟の対話に残す。

**基盤**: D層 epistemic_ledger / counterfactual_sessions / load_calculator /
verification_proposals + TheoryOperationGraph + landscape の observation/theory perspective。
伝播・経路計算はすべて非LLM・決定論・読み時導出。

### 提案4: 時間レンズ（Chronicle Lens）— 式と概念の伝記を歩く

**horizon: mid ／ 収束点3に立脚。書き込み経路ゼロ**

W層の要素検討ワークスペースに、既存4レンズ（論文内／コーパス横断／地図／承認・疑義）と
直交する第5のレンズ「時間」を追加する。L層ハブ（共通部品）起点で:

1. **形の変遷**: confirmed identity link で繋がった全インスタンスを論文の年代順に並べ、
   各時点の表記（local_expressions）と前提の差分（derivation_chain の入力仮定の増減）を提示。
2. **共同体判断の歴史**: theory_review_events に残る承認・疑義・standardization_status 遷移の
   時刻を同じ年表に重ねる（科学史家: 「式がいつ変わったか」と「共同体がいつ受け入れたか」は
   常に別の出来事。両方揃って初めて伝記になる）。
3. **破れた場所の章**（宇宙物理の強化案）: D層 refuted / challenge 記録 + identity link の組で
   「回転星では破れる → Hartle-Thorne へ分岐」のような失効と派生を必ず入れる。学生が
   「式は真理ではなく適用範囲を持つ生き物」と体得する最短路。
4. **提示は「歩く」**: journey 機構の第6の hop「時間方向」として実装し、年表を読むのではなく
   一歩ずつ踏む（HCI）。バースト区間（短期間に多数の論文で仮定が入れ替わる時期＝転換点）は
   「この時期にこの仮定を落とす論文が続きます」の事実文で提示（ネットワーク科学: temporal
   network の知見。数値なしでパラダイム転換の一次史料を歩ける形になる）。

**発展形 — 二つの伝記の対位法**（哲学者の結合案）: 共同体レベルの概念史と、個人レベルの
理解史（自分がこの概念に立てた問い・誤予測・articulated tension の時系列）を同じ画面で併置。
「あなたの1年前の理解は、1965年の定式化と同じ仮定を置いています」— 信念改訂が科学の欠陥で
なく構成要素そのものであることを、説教ではなく併置で示す（誤解の脱スティグマ化）。
併置は identity link 経由の決定論で行い、**同型かどうかの判断は本人に残す**（AI に「あなたは
歴史をなぞっている」と断定させない）。

**脳科学者の警告（対位法・過去の自分系に共通）**: 過去の誤った定式化の逐語再提示は誤概念の
記憶痕跡を再活性化し得る（continued influence effect）。①当該アンカーで現在の理解の確立を示す
構造的証拠（reconstruction match / articulated 済み）があるノードに限定 ②締めで必ず本人に
「当時の理解はどの条件下でなら成り立つか」を言語化させ、スコープ限定棄却として再符号化させる
（verification_scopes の思想の自己適用）— この2条件がない実装は誤概念のリハーサル装置に化ける。

**基盤**: L層 library_entries（local_expressions / standardization_status）+ W-β
element_identity_links（confirmed のみ）+ theory_review_events + V層版履歴 + D層 challenges +
personal_graph journey。すべて既存テーブルの読み時導出。V層の長期保存エクスポートと接続すれば
伝記自体が引用可能な一次史料になる（科学史家）。

### 提案5: 橋の生態系 — 同一性リンク層の自己持続ループ

**horizon: mid ／ ビジョン修正④「人間確定制ゆえ疎になる」鶏卵問題への解**

三案を結合し、確定リンクが増えないと旅も踏み跡も成立しない鶏卵問題を「疎性を運命ではなく
初期条件に変える」自己持続ループにする:

1. **転移の渡り鳥**（学習科学者）: 学習者があるコースで共通部品の理解を再構成で確立した後、
   別コースで同じL層ハブの別インスタンスに出会ったとき「これは以前見た何かと同じ構造かも
   しれません。どれだと思いますか？」の transfer probe を出題。判定は confirmed リンクが
   ground truth の非LLM・決定論。リビールでは両論文の local_expressions を並べ「同じ部品が
   分野によってこう違う顔をする」を見せる（far transfer に必須の mindful abstraction を、
   表現を潰さない設計哲学の副産物である「同一構造の複数の顔」で訓練する）。
   ネットワーク科学者の強化: 出題に「構造的に似ているが別物」の負例（rejected リンクの再利用
   — P4 の副産物）を必ず混ぜる。正例だけだと「何でも同じに見える」過汎化に落ちる。
2. **独立再発見の集約**: 学習者が自力で気づいた同一性候補を k-匿名（複数コホートの独立再発見
   のみ・KN-4 の教育系統として分離）で候補浮上させる。
3. **つながりの弁**（ネットワーク科学者）: 確定済みリンク+L層ハブ+atlas 骨格が張る連結構造を
   決定論計算し、「確定すると旅の連結効果が最大の candidate」を教員レビューキューの順序に翻訳。
4. 教員確定（KN-3 の弁は不変）で旅の到達域が広がり、新たな踏み跡と次の転移機会が生まれる。

**討論で確定した安全装置（3名が独立に同じ急所を指摘）**: 連結効果最大のリンクは、定義上
**誤同一視の汚染範囲も最大**。科学史家「エーテルは光学と電磁気学を見事に統合したがゆえに
半世紀の袋小路を作った」／宇宙物理「拡散方程式は熱伝導・宇宙線輸送・化学進化に同じ顔で
現れるが物理は全く別物」／哲学者「承認インセンティブが最も強く働くのが誤りコスト最大の
リンクという利害を帯びた証言の構造」。よって:
- 統合効果は**キュー順序にのみ**使い、確定者本人には判断前に接続効果の事実文を見せない
  （判断後に開示）。
- 高統合効果リンクには**独立した教員2名の確定**を要求（厳格テストの発想: 影響が大きい主張ほど
  失敗機会の多いテストを課す）。
- 監査記録に「この確定は弁により浮上した」という提示順の来歴を必ず刻む（さもないと後年、
  有機的確定とアルゴリズムに急かされた確定の区別がつかず史料価値が毀損される — 科学史家）。

**基盤**: W-β element_identity_links + L層ハブ + R層 reconstruction（elicit_mode 追加）+
personal graph journey + 既存レビューキュー。段階導入は転移プローブ単体（R層）を先行。

### 提案6: 静かな開通と欲望の小径 — 他者の気配の環境表現

**horizon: mid ／ 討論で最も懸念が集中した系統。ガードレール込みでのみ採用**

Dark Souls の血痕・Death Stranding の橋が示した「匿名・非同期・非言語の他者の気配」を、
数値ゼロで地図に描く:

- **旅人の踏みあと**: k=3 を通過した橋候補（多くの学習者が connect した2ノード間）を、
  人数・件数・濃度なしの**二値の質的表現**（草地→踏みあと）でのみ描く。justification_gap が
  溜まる箇所は「霧が濃く滞留する窪地」。誰の足あとかは絶対に見えない。
- **静かな開通**: 教員が臨界リンクを確定した瞬間は誰にも通知しない。学習者が後日その近傍を
  再訪したときにだけ、再訪差分が「前回ここは行き止まりでした。いまは論文Yへ渡る橋があります」
  を風景差として描く（メトロイドヴァニアの核心＝旧マップの行き止まりが通路に変わる瞬間。
  「気づいたら道ができていた」は通知で知らされた道より必ず強く記憶される）。
- 確定→発見→踏み固めの時間差三層が、通知もバッジも使わずに「自分たちの分野の地図が生きて
  育っている」という persistent world の集合的実感を作る。

**討論で合意された最低条件（5名が懸念を提出。情報カスケード・多様性枯渇・生成の先取り）**:
1. **ELICIT-first を社会的手がかりにも適用**: 小径は本人がその領域を一度自力で旅した（自分の
   橋かけ・予測を試みた）後にのみ表示。事前の経路選択には影響させず、事後の確認情報としてのみ
   機能させる（生成が先、社会的手がかりは後 — 脳科学者「追従で通った橋は自分で架けた橋より
   記憶に残らない」）。
2. **減衰**: 一定期間踏まれなければ草地に戻る（不可逆アトラクタの防止。Salganik らの MusicLab
   が示した rich-get-richer は二値表現でも防げない — ネットワーク科学者の自戒込みの指摘）。
3. **独立コホートで再現された道のみ表示**（別グループ・別期間。集約入力が出力に汚染される
   自己言及ループを断つ）。
4. **提示順への沈黙的反映はしない**: 環境表現（見える二値の踏みあと）のみ。見えない並べ替えは
   「誰も宣言せず誰も異議を申し立てられない正典形成」であり、宣言しない・煽らないの精神を
   裏口から破る（科学史家: 教科書の Whig history はまさにこの機構の数世代分の堆積）。
5. 骨格版の刻印（後年「地図の改訂とともに学習経路がどう移動したか」を測れる教育史データになる
   — 科学史家）。小径の隣の草地を「未踏ではなく招待」として等格に描く（哲学者）。

**基盤**: Phase B bridge-insights / core/personal_graph/bridges.py + core/privacy.py（k=3 正本）+
atlas オーバーレイ・ミニマップの霧描画 + atlas-cues 抑制ルール + 提案2の再訪差分。

## §4 討論が退けた・大幅に条件付けた案

- **スキーマ距離レンズ**（脳科学者案）: 3名が独立に棄却級の欠陥を指摘。①個人ネットワークは
  「本人が確定した痕跡」の疎なバイアス標本であり、ホップ距離は「スキーマとの距離」でなく
  「システム利用歴」を測る（確定操作をしない学習者・熟達者が全員「遠距離」誤診→足場過剰＝
  expertise reversal effect）②L層ハブ・骨格を traversal に含めるとスモールワールド性で距離が
  飽和し弁別力を失う③沈黙的な適応はゲームで実証済みの「検知されるゴムバンド」問題 — 数値を
  見せないのに序列を感じさせ、本人のみ可視のはずの個人地図が対話エンジンに常時読まれている
  監視感を生む。**救済条件**: 沈黙適応でなく提案型（「以前確かめた◯◯から入口を架けますか？」
  と本人に選ばせる）に転換。距離でなくエッジ非交差経路本数（接続度）を使い、個人グラフが
  閾値サイズ未満なら判定を棄権する fail-closed。
- **生産的つまづきの足場ライブラリ**（学習科学者案）: 内容は哲学者が絶賛（誤解＝「スコープを
  誤って拡張された局所的に正しい信念」— D層 verification_scopes の意味論を学習者の理解に適用。
  足場説明のデータ構造に D層スコープ語彙をそのまま使うべき）。ただし宇宙物理学者の警告:
  物理ドメインの「反復するつまづき」の相当部分は誤解でなく**規約の衝突**（計量符号 +--- と
  -+++・Gauss と SI・規格化の流儀）であり、k-匿名集約はこの区別ができない。規約衝突由来の
  擬似つまづきに足場説明を書くと「存在しない概念的中間形態を正典化する」。**条件**: 教員確定時に
  概念的つまづき／規約・記法の衝突／抽出ノイズの三分類を必須とし、後二者は同一性リンク（KN-2）
  や A層再解析への差し戻しに回す弁を置く。また HCI の指摘により、つまづき検知による動的提示は
  やらない（応答的提示は「いま私の間違いがリアルタイムで分類された」という監視感。教材のその
  場所への**常設＝環境的提示**にする。血痕が監視感を生まないのは場所に紐づいて常在するから）。
- **先人の旅の足跡**（科学史家案・付録A参照）: 「遺す自由」の思想は支持されたが、自分の地図への
  半透明重ね表示は「レースゲームのゴースト」問題 — 比較スコアなしでも重ねた瞬間に差分が網膜上で
  ランキングとして完成する（HCI）。**条件**: 重ね焼きでなく独立した「読み物としての旅路」
  （marginalia に忠実に単体で歩ける別ビュー）+ 交点は「この地点はあなたも通っています」の一行
  事実文のみ。著名教員の道の権威化を防ぐため、同じ領域に異なる先人の道が複数並存する状態を
  初期から見せる。

1. **予測して開ける論文リーディング**（near）

2. **眠りに持ち込む問い**（mid）

3. **スキーマ距離レンズ**（mid）
   個人ネットワークからのホップ距離で係留の深さを調整（SLIMM モデル）。→ §4 で大幅条件付け
4. **理解の相転移アーカイブ — 昨日の自分と話す**（moonshot）

   教材素材として寄贈できる導線。知識の呪いへの構造的対抗。→ 提案4 発展形・付録B「世代間徒弟制」

1. **支配項の直感道場 — 極限で式を『鳴らす』**（near）

### A.5 科学哲学者・認識論者

1. **「わたしはなぜこれを信じているのか」ビュー — 認識的来歴の可視化**（near）
   個人地図の各ノードに証言連鎖（原文→AI抽出→教員承認→本人の確定操作→検証状態）を事実文で
   併記。「理解した」と「先生がそう言った」の区別がつく大学院生を育てる。migration 不要の
   可能性が高い。学習科学者の強化案: 「自分はどちらで保持しているか」の一タップ自己分類を足し、
   「信頼で保持」ノードを R層再構成への誘いにする（表示と行為の閉ループ）。
2. **反証条件レジストリ**（mid）→ 提案3 に統合
3. **不一致の地図 — 認識的不一致を解消せず一級市民として提示する**（mid）
   説明・承認・疑義間の不一致を verbal（言葉の使い方）/ substantive（実質対立）の分類付きで
   一級オブジェクトとして記帳（AI候補→当事者教員確定）。「多声のまま安定している科学」に
   学習者が出会う。討論の条件: ①素朴相対主義への滑落防止に「何が観測されればどちらかに決着
   しうるか」（反証条件レジストリ）または「両立場が共有する前提」を必ず併記（学習科学者）
   ②本人の確定痕跡がある概念でのみ開示 —「本人がその概念と格闘した後の報酬」として出す（脳科学者）。
4. **認識的ストレステスト — 前提を一つ倒して分野全体を旅する**（moonshot）
   counterfactual 伝播を confirmed identity link と L層ハブを渡ってコーパス横断に拡張。
   Quine の「信念の網」を初めて歩けるものにする。ネットワーク科学者の強化: 倒す旅と対に
   「エッジ非交差な独立支持経路の本数」を出し、可視化が保守主義を強化する危険への構造的対抗に。
   → 提案3 と接続

### A.6 ネットワーク科学・複雑系研究者

1. **つながりの弁 — 人間確定制パーコレーションの臨界支援**（mid）
   「確定すると連結成分の統合効果が最大の candidate」を教員レビューキューへ優先浮上。
   最適パーコレーション問題のレビュー労力配分への転用。→ 提案5 に統合（安全装置込み）
2. **踏み跡の道 — 学習経路のモチーフから生まれる獣道**（near）
   本人確定 trace のみ k-匿名で通過履歴の「向き」を集約。経路の非対称性（A→B は多いが逆は稀）は
   教科書の章立てが捉えない理解の因果順序。→ 提案6 に統合（沈黙的並べ替えは討論で棄却）
3. **理論の耐荷重試験 — 分野ネットワークの頑健性プロファイル**（moonshot）
   「未検証かつ除去すると連結成分が大きく分断されるノード」＝認識論的ハブの系統的検出。
   負荷度（下流到達集合）と位相的分断効果は数理的に別物 —「負荷は中程度だが唯一の橋」を
   見逃さない。→ 提案3 に統合
4. **多重層の共鳴 — 個人ネットワークの重なり方そのものを知識にする**（mid）
   各学習者の個人ネットワークを multiplex の一層とみなし、層間の整列（教材提示への過適合＝
   多様性の枯渇）と発散（係留不足）を k-匿名で検知。「この概念周辺では学習者の結び方が教材と
   ほぼ一致しています。別解釈の説明バージョンを並置する余地があります」という事実文の示唆。
   多様性の維持を能動的に守る計器。

### A.7 学習体験デザイナー（HCI・ゲームデザイン）
