# システム統計（管理画面）

[← マニュアル索引](../README.md)

「システム統計」タブでは、全コースの解析パイプライン進捗（DSL・主張・論理要素・
理論操作グラフ）・原稿生成・音声生成の進捗と、受講者数・チャット数を一覧できます
（基本操作の要約は [システム統計を見る](../../admin_operations/system.md#stats) も
参照してください）。**このタブはシステム管理者（SYSTEM_ADMIN）ロールでログインした
ときのみ表示されます。** ヘッダー・タブナビゲーション・確認モーダルなど、管理画面に
共通の操作は [管理画面の共通操作](../teacher/10-admin-common.md) を参照してください。

## 画面の概要 {#overview}

一覧の1行が1コースに対応します。列には、コースタイトル・作成した教員（アップロード者）・
作成日時・チャンク数（教材本文の分割単位数）に加えて、解析・原稿生成・音声生成それぞれの
進捗と、受講者数・チャット往復数（コース全体の合計）が表示されます。行の解析・生成の
各列からは、そのコースのパイプライン処理を直接実行・再実行できます。

---

## 一覧の操作 {#list-controls}

### 教員で絞り込む {#teacher-filter}

一覧を、コースを作成した教員（アップロード者）で絞り込みます。既定は「全教員」（絞り込み
なし）です。選択肢は、現在の一覧に含まれる教員名から自動的に組み立てられます。

### 更新 {#refresh}

一覧をサーバから再取得します。他のタブでコースの解析・生成を進めた後など、最新の進捗を
確認したいときに押します。

### 列見出しで並べ替える {#sort-columns}

タイトル・アップロード者・日時・チャンク数・受講者数・チャット数の各列見出しを押すと、
その列で一覧を並べ替えます。列見出しの矢印（△/▽）が現在の並び順を示します。

1. 列見出しを押すと、その列で並べ替えます。初めて選ぶ列がタイトル・アップロード者の場合は
   昇順、それ以外の列（日時・チャンク数・受講者数・チャット数）の場合は降順になります。
2. 同じ列見出しをもう一度押すと、昇順⇄降順が切り替わります。

既定（未操作時）は日時の新しい順（降順）です。

## 解析・生成の実行 {#pipeline-actions}

### 解析を実行・再実行する {#run-analysis}

解析列には、DSL・主張（Claim）・論理要素（Component）・理論操作グラフ（Graph）それぞれの
進捗ミニバーと、個別またはまとめて再実行するボタンが並びます。

- 「DSL」: DSL構造抽出ステージを実行・再実行します。
- 「Claim」: 主張（claim）抽出ステージを実行・再実行します。
- 「Component」: 論理要素（component）抽出ステージを実行・再実行します。
- 「Graph」: 理論操作グラフ（component graph）の更新ステージを実行・再実行します。
- 「全解析」: 上記4ステージをまとめて実行します。

いずれもボタンを押すとその場で処理が開始され、確認ダイアログは挟まりません。処理の開始・
進行状況・完了件数はタブ上部のステータス表示に随時反映されます。

**ボタンが無効（または表示されない）場合**:

- このコースに解析対象のチャンク（教材本文の分割単位）が無い場合は「チャンクなし」と
  表示され、ボタンは表示されません。教材をこのコースのソースとして登録し、チャンクが
  作成されるまで待ってください。
- 同じコースで別の処理（解析・原稿生成・音声生成のいずれか）がすでに実行中の場合は
  「実行中...」と表示され、その処理が完了するまでボタンは表示されません。

### 原稿を生成する {#generate-script}

原稿生成列に、進捗バーと生成ボタンが表示されます。未着手（0%）のときはボタンに
「原稿生成」、一部完了しているときは「原稿再実行」と表示されます。

**ボタンが無効（または表示されない）場合**:

- チャンクが無い場合は「チャンクなし」と表示され、ボタンは表示されません。
- 同じコースで別の処理が実行中の場合は「実行中...」と表示され、ボタンは表示されません。
- 全チャンクで原稿生成が完了（進捗100%）すると、この一覧からはボタンが表示されなくなります。

### 音声を生成する {#generate-audio}

音声生成列に、進捗バーと生成ボタンが表示されます。未着手（0%）のときはボタンに
「音声生成」、一部完了しているときは「音声再実行」と表示されます。

**ボタンが無効（または表示されない）場合**:

- 原稿生成が完了（進捗100%）するまで表示されません。先に[原稿を生成する](#generate-script)
  を完了させてください。
- チャンクが無い場合は「チャンクなし」と表示され、ボタンは表示されません。
- 同じコースで別の処理が実行中の場合は「実行中...」と表示され、ボタンは表示されません。
- 全チャンクで音声生成が完了（進捗100%）すると、この一覧からはボタンが表示されなくなります。
