# マニュアル編集（管理画面）

[← マニュアル索引](../README.md)

「マニュアル編集」タブでは、利用者マニュアル（AIヘルプ応答が参照する知識源。学生・教員・
システム管理者向けの `docs/manual/` 相当）の下書き（draft）を編集し、検証を通過したものを
凍結版として配信できます。**このタブはシステム管理者（SYSTEM_ADMIN）ロールでログインした
ときのみ表示されます。** ヘッダー・タブナビゲーション・確認モーダルなど、管理画面に
共通の操作は [管理画面の共通操作](../teacher/10-admin-common.md) を参照してください。

## 画面の概要 {#overview}

ここでの編集はすべて下書き（draft）です。[凍結して配信する](#freeze) を実行するまで、
学生・教員向けのヘルプ応答には反映されません。draft は対象読者（student / teacher /
system_admin）ごとに独立しています。配信中のソース（ファイル同梱版 or DB凍結版）は
上部にバッジで表示されます。

---

## draft を編集する {#draft-editing}

### ファイルを選ぶ {#select-file}

左側の一覧から、対象読者（student / teacher / system_admin）ごとにグループ表示された
draft ファイルを選ぶと、右側のエディタに読み込まれます。選んでいるファイルは一覧内で
強調表示されます。

### 保存する {#save}

エディタで編集した内容を、選んでいる draft ファイルとして保存します。

**ボタンが無効になっている場合**: 他の編集と衝突（読み込み時点から revision が進んでいる）
した状態です。「他の編集と衝突しました。最新を読み込み直してください」という案内とともに
[再読込する](#reload) ボタンが表示されます。再読込すると保存ボタンは再度有効になります。

### 再読込する {#reload}

保存の衝突が起きたときに表示される、選んでいる draft ファイルの最新内容を読み込み直す
ボタンです。読み込み直すと、エディタ内の未保存の変更は失われます。

## 配信を管理する {#serving-management}

### 更新する {#refresh}

draft 一覧・版履歴・配信中バッジを、サーバから再取得します。

### ファイルから取込む {#seed}

現在配信されているスナップショットの内容から、draft を取り込みます。既存の draft
ファイルは上書きしません（冪等な取込です）。draft がまだ1件も無いときに、最初の下書きを
作る手段として使います。

### 凍結して配信する {#freeze}

現在の draft 一式を新しい版（バージョン）として凍結し、配信ソースを DB（凍結版）へ
切り替えます。実行前に確認ダイアログが表示されます。

凍結には検証（front-matter の対象読者一致・見出しの明示アンカー・
`docs/admin_operations/` へのリンク実在・学生向け禁止語彙など）を通過することが条件です。
違反があると版は作成されず、指摘内容がそのまま一覧表示されます。指摘を解消してから
再度実行してください。

凍結後は、リポジトリの `docs/manual/` を更新しても配信には反映されません
（[ファイル配信に戻す](#switch-to-files) まで）。

### ファイル配信に戻す {#switch-to-files}

配信ソースを、リポジトリ同梱のファイル版に切り替えます。実行前に確認ダイアログが
表示されます。既存の凍結版データ自体は削除されません。

**ボタンが無効（または表示されない）場合**: 配信ソースが既にファイル同梱版の場合は
表示されません（DB配信中のときのみ表示されます）。

### DB配信に切替える {#switch-to-db}

配信ソースを、現在の凍結版（active version）に切り替えます。実行前に確認ダイアログが
表示されます。

**ボタンが無効（または表示されない）場合**: 凍結版が1つも無い場合は表示されません。先に
[凍結して配信する](#freeze) で版を作成してください。既に DB配信中の場合も表示されません。
