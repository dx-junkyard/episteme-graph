# エラー解析（管理画面）

[← マニュアル索引](../README.md)

「エラー解析」タブでは、サーバ側で捕捉されたログを検索・閲覧し、AI解析や共有のために
コピーできます（基本操作の要約は
[エラーログを見る](../../admin_operations/system.md#error-logs) も参照してください）。
**このタブはシステム管理者（SYSTEM_ADMIN）ロールでログインしたときのみ表示され、
ログイン直後の既定タブでもあります。** ヘッダー・タブナビゲーション・確認モーダルなど、
管理画面に共通の操作は
[管理画面の共通操作](../teacher/10-admin-common.md) を参照してください。

## 画面の概要 {#overview}

一覧にはログが新しい順に並びます。既定では ERROR・CRITICAL レベルのログのみを対象に、
直近24時間分を表示します。ログ本文に含まれる Cookie・認証ヘッダーなどの機微情報は、
取得時に自動的にマスクされます。保持・返却されるログの最大件数は環境変数
`ADMIN_ERROR_LOG_MAX_ITEMS`（詳細は
[システム管理者編](04-system-admin.md#env-auth-cors) を参照）で制御されます。

---

## ログを検索する {#search}

### キーワードで検索する {#keyword-search}

入力欄にキーワードを入力し Enter キーを押すと、そのキーワードで一覧を絞り込みます。
検索対象は、タイムスタンプ・レベル・logger名・メッセージ・トレースバック・パス・
メソッド・セッションID・ユーザーID・教材ID・コースIDです（大文字小文字を区別しない
部分一致）。

### 期間を選ぶ {#time-range}

直近1時間・直近6時間・直近24時間（既定）・直近7日から検索対象の期間を選びます。選ぶと
自動的に一覧が再取得されます。

### INFOを含める {#include-info}

チェックを外している（既定）と ERROR・CRITICAL レベルのログのみが対象になります。
チェックを入れると、INFO・WARNING レベルのログも対象に加わります。切り替えると自動的に
一覧が再取得されます。

### 更新 {#refresh}

現在の検索条件（キーワード・期間・INFOを含めるかどうか）のまま、一覧を再取得します。

## ログをコピーする {#copy}

一覧の上には、コピー対象を選ぶための選択件数表示・コピー形式の選択・選択操作のボタンが
並びます。

### コピー形式を選ぶ {#copy-format}

コピーする際の書式を選びます。「AI解析用Markdown」（既定）・「JSON」・
「プレーンテキスト」から選べます。

### ログを選択する {#select-row}

各ログ項目の先頭にあるチェックボックスで、コピー対象を個別に選択・解除できます。
Shift キーを押しながらチェックすると、直前に操作した項目との間を範囲選択できます。

### 表示中を選択 {#select-all}

現在の検索条件で表示されているログをすべて選択済みにします。

### 選択解除 {#clear-selection}

現在の選択をすべて解除します。

### 選択したログをコピーする {#copy-selected}

選択中のログを、選んだコピー形式でクリップボードにコピーします。

**ボタンが無効になっている場合**: ログを1件も選択していません。ログ項目の
チェックボックスを選択するか、[表示中を選択](#select-all) を押すと有効になります。

### 表示中すべてをコピーする {#copy-visible}

選択状態に関わらず、現在の検索条件で表示されているログをすべて、選んだコピー形式で
クリップボードにコピーします。表示中のログが1件もない場合はコピーされず、その旨が
案内表示されます。
