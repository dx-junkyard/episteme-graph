# AIモデル（管理画面）

[← マニュアル索引](../README.md)

「AIモデル」タブでは、各場面（scene。パイプラインの解析ステージや学習チャットなど、
LLM を使う場面の単位）で使うモデルのシステム既定を確認・変更します。**このタブは
システム管理者（SYSTEM_ADMIN）ロールでログインしたときのみ表示されます。** ヘッダー・
タブナビゲーション・確認モーダルなど、管理画面に共通の操作は
[管理画面の共通操作](../teacher/10-admin-common.md) を参照してください。

## 画面の概要 {#overview}

表には、場面ごとに現在使われているモデルと、その出所（システム既定・環境変数・
ティア既定のいずれか）が表示されます。表示は実際のモデル名のみで、内部の性能区分
（fast/standard/deep/analysis のような「ティア名」）や金額は表示されません。

ここで変更するのはシステム全体の既定です。各教員が自分の教材アップロード・原稿スタジオ
などで個別に選んだ既定には影響しません（教員個人の既定は、各教員自身の画面でのみ
設定・解除できます）。

---

## システム既定を変更する {#system-defaults}

### 場面ごとにモデルを変更する {#change-scene-model}

1. 変更したい場面の行で「変更」を押すと、その場面で選べるモデルの一覧が展開されます。
2. 選択肢から選び、「保存」を押します。
3. 全ユーザーの既定に影響する旨の確認ダイアログが表示されるので、確認するとシステム既定
   として保存されます。

**選択肢が表示されない場合**: サーバにモデルカタログ（環境変数 `LLM_MODEL_CATALOG_PATH`）
が設定されていません。展開しても「選択肢が未設定です（モデルカタログ未設定）」とだけ
表示され、実際に選ぶことはできません。サーバの `LLM_MODEL_CATALOG_PATH` にカタログの
JSON ファイルを配置してください。

### 既定に戻す {#reset-scene-model}

その場面のシステム既定（DBに保存された上書き）を解除し、環境変数や既定のティアによる
決定に戻します。

**ボタンが無効になっている場合**: その場面にシステム既定としての上書きがまだありません。
[場面ごとにモデルを変更する](#change-scene-model) で一度も保存していない場面は、
最初から無効になっています。

## ステージ別に指定する {#stage-level}

パイプラインの個別ステージ（解析の各工程）ごとに、場面全体とは別に個別のシステム既定を
指定できます。

### ステージ別の指定一覧を開く {#stage-overrides}

「▸ ステージ別の指定（N件）」を押すと、指定済みのステージ別既定の一覧が開きます。
各行には[場面ごとにモデルを変更する](#change-scene-model)・
[既定に戻す](#reset-scene-model) と同じ「変更」「解除」ボタンがあります。

**セクション自体が表示されない場合**: ステージ別の指定が1件も無い状態です。
[ステージ別の既定を追加する](#add-stage-override) から新規に指定を作成すると、
このセクションが表示されるようになります。

### ステージ別の既定を追加する {#add-stage-override}

一覧内の「ステージ別の既定を追加」を押すと、まだステージ別の指定が無いステージから選び、
モデルを選んで保存できます。

**選べるステージが無い場合**: 「追加できるステージはありません（すべて指定済みです）」と
表示されます。すべてのステージに、すでにステージ別の指定があります。

## 関連画面への移動 {#navigation}

### 「LLM使用量」タブを開く {#usage-link}

選択したモデルの実際の使用状況を確認するために、「LLM使用量」タブへ移動します。
