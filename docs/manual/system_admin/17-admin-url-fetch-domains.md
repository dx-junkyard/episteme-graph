# URL取得の許可ドメイン（管理画面）

[← マニュアル索引](../README.md)

教員は教材管理タブから、論文の URL を指定して教材を取り込めます（「URLから取得」）。
サーバが指定された URL をダウンロードするため、**取得先はここに登録したドメインだけに
限定されます**。この区画は「AIモデル」タブの一番下にあり、**システム管理者
（SYSTEM_ADMIN）ロールでログインしたときのみ表示されます。** ヘッダー・タブ
ナビゲーション・確認ダイアログなど、管理画面に共通の操作は
[管理画面の共通操作](../teacher/10-admin-common.md) を参照してください。

## 画面の概要 {#overview}

登録済みのドメインが、ドメイン名・登録日・操作（削除）の表で一覧表示されます。
一覧の下に、新しいドメインを追加するための入力欄と「追加」ボタンが並びます。

**初期状態は空です。1件も登録されていない間、教員は URL からの取得を利用できません**
（教員の画面では取得ボタンが無効になり、「管理者が取得先ドメインを許可すると利用できます」
と表示されます）。この機能を使えるようにするには、ここでドメインを登録する必要があります。

登録されているドメイン**以外**からの取得は、教員がどんな URL を指定してもサーバ側で
拒否されます。取得の途中で別のドメインへ転送（リダイレクト）された場合も、転送先が
許可リストに無ければ同じく拒否されます。

## 許可ドメインを管理する {#manage}

### 許可ドメインの一覧 {#url-fetch-domains}

「AIモデル」タブの末尾にある「URL取得の許可ドメイン」の区画です。登録済みのドメインと
その登録日が表示されます。

**「許可ドメインは登録されていません。登録するまで教員はURLからの取得を利用できません。」と
表示される場合**: まだ1件も登録されていない状態です。これは異常ではなく初期状態です。
[ドメインを追加する](#url-fetch-domain-add) から登録してください。

**「許可ドメインの読み込みに失敗しました。」と表示される場合**: 一覧の取得に失敗しました。
タブを開き直すか、時間をおいて再度確認してください。

### ドメインを追加する {#url-fetch-domain-add}

入力欄にドメイン名を入力し、「追加」を押すと許可リストに登録されます（入力欄で Enter を
押しても同じです）。登録すると一覧が読み直され、その時点から教員が URL 取得を利用できる
ようになります。

1. 入力欄にドメイン名だけを入力します（例: `arxiv.org`）。
2. 「追加」を押します。完了すると「ドメイン ◯◯ を許可リストに追加しました。」と
   表示されます。

入力値は保存時に正規化されます（大文字は小文字に、`https://` などのスキームや末尾の
パスが付いていても、ホスト名の部分だけが保存されます）。すでに登録済みのドメインを
もう一度追加しても、重複して増えることはありません。

登録したドメインは、その**サブドメインも含めて**取得が許可されます（例: `arxiv.org` を
登録すると `export.arxiv.org` からも取得できます）。似た名前の別ドメイン
（例: `notarxiv.org`）は許可されません。

**「追加するドメインを入力してください。」と表示される場合**: 入力欄が空のままです。
ドメイン名を入力してから押してください。

**「追加に失敗しました: ドメインの形式が正しくありません: …」と表示される場合**:
入力がドメイン名として解釈できませんでした。ホスト名（例: `arxiv.org`）の形で入力し直して
ください。

### ドメインを削除する {#url-fetch-domain-remove}

一覧の各行にある「削除」を押すと、そのドメインを許可リストから外します。確認ダイアログ
（「ドメイン ◯◯ を許可リストから削除します。以後このドメインからのURL取得はできなく
なります。」）で「OK」を押すと実行されます。

- **削除後は、そのドメインからの新規の取得ができなくなります。** 教員が同じドメインの
  URL を指定すると「このURLのドメインは許可されていません」と表示されます。
- **すでに取り込み済みの教材には影響しません。** 過去にそのドメインから取得した教材、
  その解析結果、それを使ったコースはそのまま残ります。削除されるのは「これから取得して
  よい先」の登録だけです。
- 許可リストを空にすると、この機能は最初の状態（無効）に戻ります。教員の画面では取得
  ボタンが無効になり、理由が表示されます。

再び使えるようにしたいときは、[ドメインを追加する](#url-fetch-domain-add) で同じドメインを
登録し直してください。

**「削除に失敗しました: …」と表示される場合**: 一覧が古くなっていて、そのドメインが
すでに削除されている可能性があります。一覧を確認し直してください。

## 記録 {#audit}

ドメインの追加・削除は、誰がいつ行ったかが監査記録として残ります（記録の閲覧については
[システム管理者編](04-system-admin.md) を参照してください）。教員による URL 取得そのもの
（何を取得したか）は、通常のアップロードと同じ扱いで教材として記録されます。
