# discuss 観測（管理画面）

[← マニュアル索引](../README.md)

「discuss 観測」タブでは、「論文と話す」（discuss モード）の利用状況を確認できます。
**このタブはシステム管理者（SYSTEM_ADMIN）ロールでログインしたときのみ表示されます。**
ヘッダー・タブナビゲーション・確認モーダルなど、管理画面に共通の操作は
[管理画面の共通操作](../teacher/10-admin-common.md) を参照してください。

## 画面の概要 {#overview}

discuss モードの次段階（v2）に着手するかどうかを判断するための観測基盤です。集計は
仮名化済み（ユーザーIDは復元できない形に変換されています）で、学習者の発話本文・引用は
一切含まれません。ここでの「分析開始の参考目安」表示は達成状況を示すだけで、達成しても
自動的に何かが実行されるわけではありません（分析に入るかどうかは運用者が判断します）。
自動更新（ポーリング）は行わないため、最新の状況は手動で取得し直す必要があります。

---

## 観測状況を確認する {#status}

表示内容は、チャットタグ別の LLM 利用量、discuss 痕跡（会話ターン）の grounding
（教材由来／別の資料／AI生成）の内訳、UI イベント（開幕・着地・分岐チップなど）別の件数、
分析開始の参考目安の4つです。

### 取得する {#refresh}

現在の観測状況をサーバから取得し直します。自動更新は行われないため、最新の状況を見たい
ときはこのボタンを押します。

---

## 分析用ダンプを取得する {#dump}

### ダンプ (tar.gz) {#dump-targz}

分析用のダンプファイルを tar.gz 形式でダウンロードします。ダウンロードの取得は
監査記録されます。

**ボタンが無効になっている場合**: ダウンロード処理の実行中です。生成が終わると自動的に
再度押せるようになります。

### ダンプ (zip) {#dump-zip}

分析用のダンプファイルを zip 形式でダウンロードします。内容は tar.gz 版と同じで、
形式のみが異なります。ダウンロードの取得は監査記録されます。

**ボタンが無効になっている場合**: ダウンロード処理の実行中です。生成が終わると自動的に
再度押せるようになります。
