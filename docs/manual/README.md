# episteme-graph 利用者マニュアル

本マニュアルは、episteme-graph（大学院生の学習プロセスを支援する知識グラフ管理システム）を
**利用する立場の方**に向けたドキュメントです。開発者・運用者向けの設計解説は
[docs/ のトップページ](../README.md) から各ドキュメントを参照してください。

---

## 読み方

1. まず、立場を問わず全員が [仕様編](01-specification.md) を読み、システムの全体像・ロールと権限・用語を把握してください。
2. 次に、ご自身の立場に対応する「使い方編」を読んでください。

権限は「受講者 ⊂ 教員 ⊂ システム管理者」と**累積**します。
教員は受講者ができることをすべて行え、システム管理者は教員ができることをすべて行えます。
そのため、教員の方は受講者編も、システム管理者の方は教員編もあわせて読むことをおすすめします。
