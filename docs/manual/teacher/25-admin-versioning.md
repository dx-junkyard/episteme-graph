# 共有版の管理（管理画面）

## 画面の概要 {#overview}

「版の管理」は、教材の解析成果やコースを、不変のスナップショット（共有版・リリース）として
発行し、共有先の教員を所有者の一方的な更新・削除から保護する機能です。教材管理タブの各行、
コース管理タブの各行の「版の管理」ボタンから、同じモーダルが開きます（教材の開示範囲・
グループ共有とは別機能です）。

共有先の教員は、発行された版に「ピン留め」して読みます。取り込む（同意する）まで、内容は
変わりません。コースはこの版固定が読み取り全体に効きますが、教材の解析成果は現状、
版固定でのブラウズには対応しておらず、履歴の記録・更新通知・引用時の版固定のみが有効です
（共有先には引き続き最新の解析結果が表示されます）。

モーダルは所有者以外（editor・viewer）にも開けます。所有者以外には、版履歴や自分が
見ている版、削除予定のバナーは表示されますが、発行・削除予約の操作は「所有者のみ操作
できます」という理由付きで無効化されます。

## 共有版として発行する {#publish}

その時点の内容を、不変の版（リリース）として発行します。任意でメモを入力できます。
発行すると版番号が1つ進み、共有先の教員に更新通知が届きます。引用（他コースでの再利用等）は
その時点の版に固定されます。

**ボタンが無効（グレーアウト）になっている場合**: 所有者のみ操作できます。自分が所有者
ではない教材・コースを開いています。

## 版履歴を確認する {#version-history}

これまでに発行された版の一覧を、版番号・メモ・発行日時とともに確認します。現行の版には
「現行」、自分がピン留めしている版には「あなたの版」の印が付きます。読み取りのみで、
版の内容を個別に閲覧するビューはこの画面にはありません。

## 削除を予約する {#schedule-deletion}

猶予日数（既定14日）と理由（任意）を指定して、削除を予約します。予約すると共有先に通知が
届き、期限を過ぎると全ユーザーから物理的に削除されます。実行前に確認ダイアログが入ります。

**ボタンが無効（グレーアウト）になっている場合**: 所有者のみ操作できます。自分が所有者
ではない教材・コースを開いています。

## 削除予約を取り消す {#cancel-deletion}

削除予定のバナーに表示される「削除予約を取り消す」で、猶予期間中であれば予約を取り消せます。
期限を過ぎると取り消せません（物理削除されます）。

**ボタンが無効（グレーアウト）になっている場合**: 所有者のみ操作できます。自分が所有者
ではない教材・コースを開いています。

## 通知インボックス {#inbox}

ヘッダーの 🔔 通知ボタンから、共有版の更新・削除予約・削除・解析完了などの通知一覧を
確認できます。未読件数はボタン横のバッジに表示されます。

### 通知を確認する・すべて既読にする {#inbox-read}

通知をクリックすると既読になります。「すべて既読」を押すと、一覧に表示されている通知を
まとめて既読にできます。

### 更新を取り込む・更新を確認する {#inbox-adopt}

新しい版が発行された通知には「取り込む」（コースの場合）または「更新を確認」（教材の
解析成果の場合）ボタンが表示されます。押すと、自分のピン留めを最新の版に進めます
（コースは以降その版の内容を読むようになります。教材は版固定でのブラウズに対応していない
ため、確認した記録が残るのみです）。

取り込み中はボタンの文字が「取り込み中...」に変わります。取り込みに失敗した場合は
「再読み込みしてください」と表示され、通知は未読のまま残ります。
