# グループ管理（管理画面）

[← マニュアル索引](../README.md)

## 画面の概要 {#overview}

「グループ管理」タブでは、教材・コースをグループ内限定で共有したり、他の教員・受講者を
グループに招待したりします。グループは複数の教員・受講者をまとめる箱で、開示範囲を
「グループ限定（group）」にした教材・コースは、そのグループに参加しているメンバーだけが
閲覧できます。グループの詳細な位置づけ（RBAC・開示範囲との組み合わせ）は
[認証・権限・開示範囲](../../features/auth-visibility.md) を参照してください。各操作の手順は
[グループ管理タブの操作](../../admin_operations/users.md#manage-groups) にもまとまっています。

このタブはシステム管理者（SYSTEM_ADMIN）にも表示されます。グループの作成・参加は
教員・システム管理者のどちらでも行えます。

画面はおおむね次の順に並んでいます。

1. 自分宛の未承諾の招待（あれば）
2. 招待コードで参加するフォーム
3. グループを作成するフォーム
4. 自分が参加しているグループの一覧（アコーディオン形式）

---

## 招待への対応 {#invitation-response}

### 未承諾の招待：承諾・辞退 {#my-invitations}

他の教員から直接招待（ユーザー指定招待）を受けている場合、画面上部に招待元グループ名と
招待者のユーザー名が一覧表示されます。

1. 「承諾」を選ぶと、そのグループのメンバー（member ロール）として参加します。
2. 「辞退」を選ぶと、招待を辞退します（グループには参加しません）。

どちらの操作も追加の確認は挟まらず、その場で反映されます。

**この欄が表示されない場合**: 自分宛の未承諾の招待が1件もありません。招待コードを持って
いる場合は、下記の「招待コードで参加する」を使ってください。

---

## グループへの参加・作成 {#join-and-create}

### 招待コードで参加する {#join-form}

グループの管理者（admin ロールのメンバー）から受け取った招待コードを入力してグループに
参加します。

1. 「招待コードを入力...」欄にコードを入力します。
2. 「招待コードで参加」を選びます。

参加済みのグループのコードを入力した場合はエラーにならず、そのまま（重複せずに）現在の
参加状態が維持されます。存在しないコードを入力した場合はエラーメッセージが表示されます。
入力欄が空のまま「招待コードで参加」を選んでも何も起こりません。

### グループを作成する {#create-form}

新しいグループを作成します。作成した本人が、そのグループの最初の管理者（admin ロール）
になります。

1. 「新規グループ名...」欄にグループ名を入力します（必須）。
2. 「説明」欄に説明文を入力します（任意）。
3. 「グループを作成」を選びます。

グループ名が未入力のまま作成しようとすると、フォーム下にエラーメッセージが表示され、
作成されません。作成に成功すると、発行された招待コードがメッセージ内に表示されます
（招待コードは後から「所属グループ」欄でも確認できます）。

---

## グループ一覧とメンバー管理 {#member-management}

「所属グループ」欄には、自分が参加している（メンバーである）グループが一覧表示されます。
自分が admin ロールかどうかで、開ける操作の範囲が変わります。

### グループの詳細を開く {#list}

一覧の各グループの見出し行を選ぶと、そのグループの詳細（説明文・メンバー表・招待コードなど）
が展開されます。もう一度選ぶか、別のグループの見出し行を選ぶと開閉が切り替わります。

グループ名の右に「(admin)」と表示されている場合、自分がそのグループの管理者であることを
示します。

### メンバーを除名する {#remove-btn}

管理者が、admin ロール以外のメンバーをグループから除名します。メンバー表の対象行にある
「除名」を選ぶと、確認なしにその場で除名されます。

**このボタンが表示されない場合**: 自分がそのグループの admin ロールでない場合、
（または対象行が admin ロールのメンバーである場合）は表示されません。除名したい場合は、
そのグループの管理者に依頼してください。

### グループを退会する {#leave-btn}

admin ロール以外のメンバーが、自分自身をグループから退会させます。自分の行にある
「退会」を選び、確認ダイアログで「OK」を選ぶと退会します。

**このボタンが表示されない場合**: 自分がそのグループの admin ロールの場合は表示されません
（admin 自身の退会操作には現在対応していません）。グループから離れたい場合は、グループの
削除、または他の管理者への相談を検討してください。

### 招待コードを再発行する {#rotate-btn}

現在の招待コードを無効化し、新しいコードを発行します。既に配布済みの古いコードでは
参加できなくなります。「再発行」を選ぶと確認なしにその場で反映されます。

**このボタンが表示されない場合**: 自分がそのグループの admin ロールでない場合は
表示されません。招待コードの再発行が必要な場合は、そのグループの管理者に依頼してください。

### ユーザーを直接招待する {#invite-btn}

招待コードを共有せずに、特定のユーザー名を指定してグループへ招待します。招待された側には
「未承諾の招待」として表示され、相手が承諾するまでメンバーにはなりません。

1. 「ユーザー名」欄に招待したい相手のユーザー名を入力します。
2. 「招待」を選びます。

指定したユーザー名が存在しない場合や、既にそのグループのメンバーである場合はエラー
メッセージが表示されます。入力欄が空のまま「招待」を選んでも何も起こりません。

**このボタンが表示されない場合**: 自分がそのグループの admin ロールでない場合は
表示されません。ユーザーの招待が必要な場合は、そのグループの管理者に依頼してください。

### グループを削除する {#delete-btn}

グループそのものを削除します。「グループを削除」を選ぶと確認ダイアログが表示され、
「削除する」を選ぶと確定します。

**削除すると元に戻せません。** グループのメンバー情報・招待情報も合わせて削除されます。
そのグループを参照していた教材・コースの開示範囲設定は、グループ指定が外れて
「グループ限定」ではなくなります（教材・コース自体は削除されません）。

**このボタンが表示されない場合**: 自分がそのグループの admin ロールでない場合は
表示されません。グループの削除が必要な場合は、そのグループの管理者に依頼してください。
