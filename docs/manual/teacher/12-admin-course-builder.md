# コース構築（管理画面）

[← 教員編に戻る](03-teacher.md#course-management)

「コース構築」タブでは、AI とチャットしながらコースの構成（章・トピック）を設計します。
承認して登録するまでは下書き（セッション）の状態で、何度でもやり直せます。登録後の
公開・開示範囲・削除といった運用は
[コース管理（管理画面）](13-admin-course-management.md) で行います。

## 画面の概要 {#overview}

画面は左側がチャット欄、右側がコース構成プレビューの2ペイン構成です。左ペイン上部には
過去のセッションを選び直すためのセッションバー、その下に「使用する教材を選択」の教材
選択パネルがあります。教材を選び、チャットで要望を伝えると、右ペインにコース構成
（章立て・トピック）のプレビューが表示され、対話を重ねて調整できます。

## セッションを選ぶ {#session-management}

コースビルダーとの対話はセッションとして PostgreSQL に保存されます。ページを
リロードしても、セッションを選び直せば続きから設計できます。

### 過去のセッションを選択 {#session-select}

セッションバーのドロップダウンから、これまでに作成したセッションを選び直せます。
選択するとチャット履歴と、そのときのコース構成プレビューが復元されます。既にコースを
登録済みのセッションは、選択肢の末尾に「[登録済]」と表示されます。

### + 新規 {#new-session-btn}

現在の対話をリセットし、新しいセッションとして最初から設計を始めます。教材の選択・
チャット履歴・コース構成プレビューはすべてクリアされます（既存セッションは削除
されません。単に選択が外れるだけです）。

### 既存コースを読込 {#import-course-btn}

登録済みのコースを選び直して、コースビルダーで再編集できます。押すと自分が持つ
コースの一覧がモーダルで表示されるので、対象コースの「選択 →」をクリックします。
現在のコース構成が JSON としてプレビューに読み込まれ、「第3章に新しいトピックを
追加して」のような指示で調整を続けられます。

一覧の各行には「削除」ボタンもあり、そのコースを直接削除できます。**削除は取り消せません。**
削除ボタンを押すと確認モーダルが開き、対象のコース名を確認欄に一字一句正確に入力する
までは「削除する」ボタンが押せません（誤操作防止のための名前一致確認）。

## 使用する教材を選ぶ {#material-selection}

コースの素材となる教材を選びます。1件も選ばずにチャットを送ることもできますが、
AI が参照できる教材が無いと具体的なコース構成を提案できません。選択件数の上限は
ありません（複数選択可）。

### 教材を検索する {#material-search}

検索欄にファイル名やタイトルの一部を入力すると、一覧がその場で絞り込まれます。

### 並び替える {#material-sort}

「新しい順（アップロード）」「直近の生成順」「タイトル順」「ボリューム順（チャンク数の
多い順）」から選べます。

### 絞り込みタブ {#material-filter}

「すべて」「コース未作成」「直近の生成」「解析完了」のタブで一覧を絞り込めます。
「コース未作成」はまだコースが作られていない教材、「直近の生成」は解析が完了した
日時が新しい順に並び替えたビューです。

### 教材カード（選択） {#material-card}

カードをクリックすると、コースの素材としてチェック（✓）が付きます。もう一度クリック
すると選択を解除します。

**ボタンが無効（グレーアウト）になっている場合**: その教材の解析が完了していないため
です（未解析・解析中・解析失敗のいずれか）。カードには「解析が完了すると選択できます」
と表示されます。「教材管理」タブで解析状況を確認し、完了を待つか、解析に失敗している
場合は再解析を行ってください。

## AIモデルを選ぶ {#model-chip}

チャット欄右上に、このコース構築チャットが使う AI モデル名を表示するチップがあります。
クリックするとカタログに登録されたモデルの一覧が開き、選び直せます。「既定に戻す」を
選ぶと、システムで設定された実効モデルに追従する状態に戻ります。

選択はセッション単位でこのページに滞在中のみ保持され、サーバには保存されません
（ページを再読み込みすると既定の表示に戻ります）。モデルを切り替えると、以降の応答が
そのモデルになることがチャット欄に区切り線として表示されます。

**選択メニューが開かない場合**: モデルカタログを取得できていないためです（未設定・
取得失敗など）。この場合はモデル名の表示のみになり、既定のモデルで応答します。

## チャットでコースを設計する {#chat}

チャット欄に「どんな受講者向けに、何を学べるコースにしたいか」を書いて送信すると、
AI がコース案（章・トピック構成、前提知識の順序を含む）を提案し、右ペインのプレビュー
に反映されます。対話を重ねて「第3章にトピックを追加して」のように調整できます。

既存コースを読み込んで再編集している場合は、読み込んだ構成が自動的に AI へのコンテキ
ストとして最初の対話に含まれます。

### 送信 {#send-btn}

入力欄の内容を送信します。Enter キーでも送信できます（Shift+Enter は改行、日本語入力の
変換確定中の Enter は送信されません）。

## コースを登録する {#approve}

コース構成プレビューが表示されると、その下に登録ボタンが現れます。

### 承認してコースを登録 {#approve-btn}

現在のプレビュー内容を、実際に受講可能なコース（テンプレート）として登録します。
登録すると、選択した教材が `sources` として紐づけられ、章立てが `chapters` に、
トピックは前提知識（`prerequisites`）付きで登録されます。同時にコース原稿・音声の
自動生成と、教材の解析パイプライン（DSL → Claim → Component → Graph）が開始されます。

登録直後は、このセッションを使って同じコースを再登録することはできません。別のコース
として再度登録したい場合は「+ 新規」で新しいセッションを作成してください。

登録後の公開・開示範囲・削除・共有版の管理は
[コース管理（管理画面）](13-admin-course-management.md) から行います。

**ボタンが無効（グレーアウト）になっている場合**: このセッションが既に一度コース登録
済みだからです。ボタンの表示も「登録済み」に変わります。同じ下書きから再度登録する
ことはできません。「+ 新規」で新しいセッションを作成し、そこから登録し直してください。

## 登録直後の確認ウィザード（学習マップ割り当てを含む） {#atlas-binding-after-register}

コースを登録すると、そのまま
[リリース前の確認](13-admin-course-management.md#release-review-modal)ウィザードが自動で
開きます。「学習マップの割り当て → 論文の位置づけ → 公開」の3ステップで、AI が作った
内容を確認しながら公開まで進められます。各ステップには「あとで」があり、飛ばしても
かまいません（飛ばしても受講者への表示は変わりません）。あとから「コース管理」タブの
[確認して公開](13-admin-course-management.md#release-review-btn)で同じウィザードを
開き直せます。

ウィザードの1ステップ目が学習マップの割り当てです。ここでコースのトピックと、分野の地図
（Field Atlas）の骨格概念との対応を確認し、「この対応で次へ」で保存します。保存するまで
確定せず、後から「コース管理」タブの「学習マップ編集」からいつでもやり直せます。詳しい
操作は
[学習マップ（分野の地図）を割り当てる](../../admin_operations/course.md#atlas-binding)
を参照してください。

対応する分野の骨格が凍結されていない場合は「対応する分野マップは見つかりませんでした」
という事実文が表示されます。今すぐ割り当てなくても問題はなく、後から「次にやること」
パネルや「コース管理」タブから再開できます。

なお、ウィザードが読み込まれていない環境では、代わりにプレビュー欄の下に
「次のステップ: 学習マップの割り当て（分野の地図への配置・提案）」の枠だけが表示されます
（内容・操作は上記の1ステップ目と同じです）。
