# 管理画面の共通操作

管理画面（`/admin.html`）のどのタブでも共通して使う、ヘッダー・タブナビゲーション・
確認モーダルについて説明します。各タブ固有の操作は、タブごとの節（例:
[教材管理タブの操作](11-admin-materials.md)）を参照してください。

## 画面の概要 {#overview}

管理画面の上部には、常にヘッダー（ロゴ・学習画面へのリンク・ユーザー名・
📋 次にやること・🔔 通知・❓ 使い方・ログアウト）とタブナビゲーションが表示されます。
タブの下に、選んでいるタブの内容が表示されます。

見えるタブ・ボタンはロールによって異なります。教員（TEACHER）にはコンテンツ系タブ
（教材管理・コース構築・コース管理・原稿スタジオ）が表示されますが、システム管理者
（SYSTEM_ADMIN）としてログインするとこの4タブは表示されず、代わりにシステム統計・
LLM使用量・エラー解析・マニュアル編集・discuss 観測・AIモデルのタブが表示されます
（管理画面上ではコンテンツ運用は教員ロールでのログインを前提とした画面構成です）。

## タブナビゲーション {#tab-navigation}

### タブグループ（プルダウン） {#tab-groups}

画面上部のタブは「コンテンツ」「学習インサイト」「ナレッジ基盤」「運用」の4グループに
束ねられており、グループ名を押すとそのグループに属するタブの一覧がプルダウンで開きます。

1. グループ名（例:「コンテンツ」）を押すと、そのグループのタブ一覧が開きます。
2. タブ名を押すとそのタブに切り替わり、プルダウンは自動で閉じます。
3. 開いているプルダウンの外側を押すと、選択せずに閉じます。

現在選んでいるタブの名前は、閉じた状態でもグループ名の隣に小さく表示され続けるため、
どのタブを見ているかはプルダウンを開かなくても確認できます。

タブの切り替えごとに、📋 次にやることの内容がサーバから再取得されます
（自動更新の頻度は画面遷移のタイミングのみで、定期的なポーリングは行いません）。

## ヘッダーのボタン {#header-buttons}

### 📋 次にやること {#next-steps}

現在の教材・コースの状態から導出した「次にやるべきこと」を一覧表示します。件数のみが
バッジとして表示され、パネルは自分で開くまで自動的には開きません。

1. ヘッダーの「📋 次にやること」を押すとパネルが開き、項目が重要度順
   （● 必要 / ○ 推奨 / ・任意）にグループ表示されます。
2. 各項目の「案内する」を押すと、該当タブへの移動と入力箇所の点灯（道案内）が行われます。
   道案内は画面遷移と点灯のみを行い、値の入力や保存は行いません。
3. 「今はしない」を押すとその項目は一覧から消え、パネル下部の「非表示にした項目」に移ります。
   これは完了扱いにする操作ではなく、後から「元に戻す」でいつでも一覧に戻せます。

項目は完了フラグを持たず、対応する状態（例: 教材の解析完了、コースの公開）が変化すると
サーバ側の判定で自動的に一覧から消えます。表示件数には上限があり、上限に達している場合は
その旨がパネル内に表示されます（対応が終わると次の項目が表示されます）。

**「非表示にした項目 (N)」が押せない（グレーアウトしている）場合**: 今のところ
「今はしない」で非表示にした項目が1件もありません。いずれかの項目で「今はしない」を押すと
件数が増え、押せるようになります。

### 🔔 通知 {#notifications}

共有物（教材・コースの共有版）の更新・削除予約・削除、解析やレクチャー原稿・音声の完了/失敗、
分野の地図の骨格の凍結・廃止など、状態管理・通知基盤からの通知インボックスです。

1. 「🔔 通知」を押すと通知の一覧が開きます。未読件数はボタンの隣に表示されます
   （9件を超える場合は「9+」と表示されます）。
2. 通知を押すとその通知は既読になります。「すべて既読」で一括既読にできます。
3. 共有版の更新通知には「取り込む」（教材の場合は「更新を確認」）ボタンが付くことがあり、
   押すと本人のピン留めをその時点の最新版へ進めます。

一覧は自動では更新され続けます（60秒間隔のポーリング）が、パネルを開いたままにしなくても
未読件数バッジは最新の状態を反映します。

### 🤖 操作アシスタント {#copilot}

管理画面の操作について、AI に説明・道案内・簡単な代行操作を頼めるチャット型アシスタント
です（画面右下に常設されています）。

1. 右下の「🤖」ボタンを押すとチャットパネルが開きます。
2. 操作について質問すると、説明（画面の使い方）・道案内（該当タブへの移動+入力箇所の点灯）・
   代行（実際にその場で操作を実行）のいずれかで応答します。どの操作を代行できるかは
   ログイン中のロールで決まり、権限が無い操作は代行されません。
3. 取り消せない操作（削除・公開・凍結など）を代行する前には、必ず実行前の確認が挟まります。
4. 直前にアシスタントが代行した操作は「↩ 戻す」で取り消せることがあります。

**「↩ 戻す」が押せない（グレーアウトしている）場合**: このセッション中にアシスタントが
代行した操作がまだ1件もありません。何か代行操作を行うと押せるようになります。
（すでに代行操作がある状態で「↩ 戻す」自体は押せても、その操作が取り消せない性質のもの
だった場合は、押すと「取り消せない操作です」という案内が表示されるだけで、何も変更は
行われません。）

### ❓ 使い方（インスペクト） {#inspect-mode}

画面の各部品（ボタンやタブなど）が何のためにあるのか、その場で確認できる機能です。
学習画面の同名機能と同じ仕組みで、管理画面向けに部品の説明が用意されています。

1. ヘッダーの「❓ 使い方」ボタンを押すと、インスペクト・モードが ON になります。
2. ON のまま、知りたい部品（ボタンやタブなど）にカーソルを合わせると、その部品の使い方が
   吹き出しで表示されます。
3. Esc キーを押すと、インスペクト・モードは終了します。ON の間に部品をクリックしても、
   その部品本来の操作（送信・削除など）は実行されません。

カーソルを合わせた部品の説明がまだ用意されていない場合は、その旨が表示されます。

### ログアウト・ユーザー表示 {#logout}

ヘッダー右側には、ログイン中のユーザー名、学習画面（`/`）への切り替えリンク、
「ログアウト」ボタンが常に表示されます。

- 学習画面へのリンクを押すと、受講者向けの学習画面に切り替わります（管理画面のログイン状態は
  保持されたままです）。
- 「ログアウト」を押すと、その場でログアウトし、ログイン画面に戻ります。取り消し確認は
  ありません。

## 確認モーダル {#confirmation-modals}

削除・公開・凍結など影響の大きい操作の前に共通で使われる、2種類の確認モーダルです。
各タブの操作固有の説明は、それぞれのタブの節（例:
[教材を削除する](../../admin_operations/materials.md#delete)）を参照してください。

### 危険確認モーダル {#danger-confirm-modal}

不可逆・影響の大きい操作（パイプラインの再実行、教材やコースの公開など）の前に表示される
2段階確認です。ブラウザ標準の確認ダイアログとは異なり、明示的にボタンを押さないと
先に進めません。

1. 操作を実行しようとすると、タイトルと説明文を伴ったモーダルが表示されます。
2. 「キャンセル」を押すか、モーダルの外側をクリックすると、何も実行せずに閉じます。
3. 実行ボタン（表示ラベルは操作によって異なります。例:「実行する」「公開する」）を押すと、
   その場で操作が実行されます。

### 削除確認モーダル {#delete-confirm-modal}

教材・コースの削除など、取り消せない削除操作の前に表示される確認です。危険確認モーダルより
厳しく、対象の名前を正確に入力しないと削除を実行できません。

1. 削除しようとしている対象の名前が表示されます。
2. 入力欄に、表示されている名前を1文字も違わず入力します。
3. 入力した文字列が対象の名前と完全に一致すると、「削除する」ボタンが押せるようになります。

**「削除する」ボタンが押せない（グレーアウトしている）場合**: 入力欄の文字列が対象の名前と
完全に一致していません。表示されている名前をそのまま正確に入力してください。
