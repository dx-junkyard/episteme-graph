# 学生管理（管理画面）

[← マニュアル索引](../README.md)

## 画面の概要 {#overview}

「学生管理」タブでは、受講者（STUDENT）のアカウントを作成します。教員（TEACHER）以上の
ロールであれば、このタブから直接アカウントを発行できます。

このタブは「グループ管理」タブとは別の画面です。**アカウントそのものを新規に作るのは
ここ**（学生管理タブ）で、作成したアカウントを特定のグループに参加させたい場合は、
別途「グループ管理」タブから招待コードの共有やユーザー招待を行います
（[グループ管理](15-admin-groups.md#overview) を参照）。学生管理タブ自体にはグループを
指定する項目はありません。

## 学生アカウントの作成 {#create-form}

### 学生を作成する {#student-form}

新しい受講者（STUDENT）アカウントを作成します。手順の詳細は
[学生アカウントを作成する](../../admin_operations/students.md#create-student) も参照してください。

1. 「ユーザー名」欄にログイン用のユーザー名を入力します（必須）。
2. 「メールアドレス」欄にメールアドレスを入力します（任意）。空欄のまま作成すると、
   ユーザー名から自動生成されたメールアドレスが割り当てられます。
3. 「パスワード」欄に初期パスワードを入力します（必須）。
4. 「学生を作成」を選びます。

ユーザー名・パスワードが未入力のまま送信しようとすると、ブラウザの入力チェックで
送信がブロックされます。送信すると確認ダイアログを挟まず、その場でアカウントが
作成されます。

作成したユーザー名が既に使用されている場合は、フォーム下にエラーメッセージが表示され、
アカウントは作成されません。作成に成功すると、作成した学生のユーザー名を含む成功
メッセージが表示され、フォームは空欄に戻ります。

作成した受講者のログイン情報（ユーザー名・初期パスワード）は、本人に個別に伝えてください。
受講者自身によるアカウントの新規登録はできません。
