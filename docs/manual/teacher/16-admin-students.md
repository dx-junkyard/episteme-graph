# 学生管理（管理画面）

[← マニュアル索引](../README.md)

## 画面の概要 {#overview}

「学生管理」タブでは、受講者（STUDENT）のアカウントを作成します。教員（TEACHER）以上の
ロールであれば、このタブから直接アカウントを発行できます。

このタブは「グループ管理」タブとは別の画面です。**アカウントそのものを新規に作るのは
ここ**（学生管理タブ）で、作成したアカウントを特定のグループに参加させたい場合は、
別途「グループ管理」タブから招待コードの共有やユーザー招待を行います
（[グループ管理](15-admin-groups.md#overview) を参照）。学生管理タブ自体にはグループを
指定する項目はありません。

---

## 学生アカウントの作成 {#create-form}

### 学生を作成する {#student-form}

新しい受講者（STUDENT）アカウントを作成します。手順の詳細は
[学生アカウントを作成する](../../admin_operations/students.md#create-student) も参照してください。

1. 「ユーザー名」欄にログイン用のユーザー名を入力します（必須）。
2. 「メールアドレス」欄にメールアドレスを入力します（任意）。空欄のまま作成すると、
   ユーザー名から自動生成されたメールアドレスが割り当てられます。
3. 「パスワード」欄に初期パスワードを入力します（必須）。
4. 「学生を作成」を選びます。

ユーザー名・パスワードが未入力のまま送信しようとすると、ブラウザの入力チェックで
送信がブロックされます。送信すると確認ダイアログを挟まず、その場でアカウントが
作成されます。

作成したユーザー名が既に使用されている場合は、フォーム下にエラーメッセージが表示され、
アカウントは作成されません。作成に成功すると、作成した学生のユーザー名を含む成功
メッセージが表示され、フォームは空欄に戻ります。

作成した受講者のログイン情報（ユーザー名・初期パスワード）は、本人に個別に伝えてください。
受講者自身によるアカウントの新規登録はできません。

## 学生アカウントの運用 {#operations}

### 学生アカウント一覧 {#user-list}

作成フォームの下に、受講者（STUDENT）アカウントの一覧が表示されます。列は「ユーザー名 /
メール / 状態 / 最終ログイン / 最終アクセス / 操作」です。

- **状態**: 「有効」「停止中」「削除予定」「削除済み」のいずれかが表示されます。
  「削除済み」の行には操作ボタンが表示されません。
- **最終ログイン**: 最後にログインに成功した日時です。記録がなければ「—」になります。
- **最終アクセス**: 最後に画面・APIを利用した日時です。書き込みを抑えるため数分間隔で
  更新される目安の値で、秒単位の正確さはありません。

一覧は、このタブを開いたとき、操作が成功したとき、「一覧を更新」を選んだときに読み込まれます。
自動更新は行いません。検索欄にユーザー名またはメールの一部を入力して Enter キーを押すか
「一覧を更新」を選ぶと、一致するアカウントだけが表示されます。

この一覧と最終ログイン・最終アクセスは、アカウントの運用（使われていないアカウントの確認、
ログインできないという申告への対応）のために表示しています。**学習の評価には使いません。**
個々の学習者のログイン記録・AI利用実績の詳細は、教員（TEACHER）には表示されません
（システム管理者のみが確認できます）。

### 停止と再開 {#user-suspend}

**停止**（「停止…」）は、そのアカウントのログインを拒否する操作です。教員（TEACHER）以上で
実行できます。

1. 対象の行で「停止…」を選びます。
2. 停止の理由の入力を求められます。**理由は必須です**（記録に残ります）。空欄のまま進めると
   「停止の理由を入力してください」と表示され、停止は実行されません。
3. 入力すると、その場で停止が実行されます。

停止の効果は**ログインの拒否だけ**です。停止しても、そのアカウントの受講状態・学習履歴は
消えません。コースの公開状態や他の受講者への影響もありません。再開すれば、そのまま学習を
続けられます。

**再開**（「再開」）は、停止中のアカウントを有効に戻します。理由の入力はありません。

**「停止…」が無効（押せない状態）になっている場合**: 対象が自分自身のアカウント、または
システムが最初に作成した `Administrator` アカウントです。この2つは、システムから誰も入れなく
なる事故を防ぐため停止できません。

### 表示されない操作について {#admin-only-operations}

学生アカウントのパスワード再設定・利用状況の表示・削除予約は、**システム管理者
（SYSTEM_ADMIN）のみ**が実行できます。教員（TEACHER）ロールでは、これらのボタン自体が
表示されません。

- 学生がパスワードを忘れた場合は、システム管理者に再設定を依頼してください（教員が
  学生のパスワードを再設定することはできません）。
- 卒業・退学などでアカウントを整理したい場合も、システム管理者に依頼してください。
