# つまづきデータ（管理画面）

[← 教員編に戻る](03-teacher.md#learner-dashboard)

「つまづきデータ」タブ（ヘッダーの「学習インサイト」グループ）では、RAG 検索で教材から
回答できなかった学習者の質問（未回答クエリ）を、コース単位の一覧で確認します。教材の
補強やコース改善に使うためのデータで、学習者の評価には使用しません。

## 画面の概要 {#overview}

コース選択プルダウンと、そのコースの未回答クエリ一覧だけで構成される、読み取り専用の
画面です。他のタブの操作と連動する要素はありません。

## コースを選んで確認する {#course-and-list}

### コース選択 {#course-select}

つまづきデータを確認したいコースを選びます。

1. プルダウンから対象のコースを選びます。
2. 選択すると、そのコースの未回答クエリ（日時・学生名・トピック・質問内容）が
   一覧表示されます。
3. 別のコースを選び直すと、一覧はそのコースの内容に自動で切り替わります。

コースを選んでいない間、一覧には「コースを選択してください」と表示されます。

### 更新 {#refresh-btn}

選択中のコースの一覧を最新の状態に読み込み直します。他の学習者が新たに質問した後などに
使います。

### 一覧の見方 {#table}

コースの未回答クエリを日時の新しい順に一覧表示します（最大200件）。列は日時・学生名・
トピック・質問内容です。

この一覧は**個人を匿名化しない、実名（表示名）付きの生データ**です。教材のどこを
補強すべきかを具体的に判断できるよう、あえて質問の内容と学生名をそのまま表示しています。
該当データがまだ無い場合は「つまづきデータはまだありません」と表示されます。一覧からの
編集・削除はできません。

## 他の集計画面との違い {#relation-to-aggregates}

原稿スタジオの「つまづき」ペイン（claim 単位のサマリー）や
[関心集約](21-admin-interest-dashboard.md#overview) タブの集計は、本タブの一覧とは別に、
**k-匿名化（k=3）**で保護された集団集計として提供されています。該当する学習者が3人未満
（n<3）の項目は表示されず、件数も生の数値ではなくレンジ（3-5 / 6-10 / 11+）で表示されます。
これは個々の学習者を特定できないようにするための保護で、対象を絞って具体的に改善点を
探したいときは本タブの一覧を、クラス全体の傾向をつかみたいときは集計画面を、というように
使い分けます。いずれのデータも学習者の評価に使用することは禁止されています。
