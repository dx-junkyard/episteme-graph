# スキーマ提案（管理画面）

[← 教員編に戻る](03-teacher.md#schema-proposals)

「スキーマ提案」タブ（ヘッダーの「ナレッジ基盤」グループ）では、AI が提案したスキーマ
拡張（新しい概念タイプ・述語）を、シミュレーション（Shadow Testing）で影響を確認してから
承認・却下します。提案は承認されるまでシステムには反映されません。

提案そのものの生成は、このタブではなく
[DSL進化分析（管理画面）](23-admin-schema.md#overview) タブの「AIメタ分析を実行」から
行います。本タブは、すでにある提案を**シミュレーションで検証したうえで**承認する画面です
（DSL進化分析タブには、シミュレーションを介さずに直接承認・却下する別のフローも
あります。詳しくは同ページを参照してください）。

## 画面の概要 {#overview}

提案一覧・シミュレーション結果・承認アクションの3つの領域で構成されます。シミュレーション
結果と承認アクションは、いずれかの提案でシミュレーションを実行するまで表示されません。

## 提案一覧 {#proposals-list}

未回答クエリの分析から生成されたスキーマ拡張提案が、カードで一覧表示されます。各カードには
提案の要約・状態（保留中 / 承認済 / 却下）・理由・提案アイテム（概念 / 関係の種別・キー・
説明）・分析対象のクエリ数・作成日時が表示されます。

提案がまだ無い場合は「提案はまだありません。「DSL進化分析」タブからAIメタ分析を実行して
ください。」と表示されます。この一覧自体は読み取り専用で、保留中の提案にのみ次の
「シミュレーションを実行」ボタンが表示されます。

### シミュレーションを実行 {#simulate-btn}

保留中の提案について、既存の教材にスキーマ拡張を適用した場合の影響を事前に確認します。

1. 保留中の提案カードの「シミュレーションを実行」を押します。
2. 提案のトリガーとなった教材（Target）・同系統の教材（Similar）・関連性の低い教材
   （Control）に対する影響がシミュレーションされ、下に「シミュレーション結果」が表示
   されます。

実行中はボタンが「シミュレーション中...」に変わり押せなくなります。完了すると
「シミュレーション完了」表示に変わります。対象教材が不足しているなどの理由で失敗した
場合は、ボタンが押し直せる状態に戻ります。もう一度実行するか、対象教材を確認してください。

## シミュレーション結果 {#simulation-result}

シミュレーションを実行すると表示される、読み取り専用の結果です。

- 上段: Target / Similar / Control 各教材数と、追加コンセプト・削除コンセプト・
  再分類ノードの合計件数。
- 下段: Target / Similar / Control それぞれの教材ごとに、追加・削除されたコンセプトや
  リレーション、再分類されたノードの詳細（変化が無い教材は「変化なし」、対象教材が無い
  区分は「対象ドキュメントなし」と表示されます）。

この結果を確認したうえで、下の「承認アクション」で適用するかどうかを判断します。

## 承認する {#approve-actions}

シミュレーションの完了後に表示される、承認のための操作です。

### システム全体に適用 {#approve-full-btn}

シミュレーションした提案を、全教材を対象にシステム全体へ適用します。

1. 「システム全体に適用」を押すと、確認ダイアログ（「スキーマ提案をシステム全体に適用し、
   全教材の再抽出ジョブを開始します。この操作は取り消せません。」）が表示されます。
2. 「適用する」を押すと、その場でスキーマへ反映され、全教材を対象にした再抽出ジョブが
   開始されます。**取り消せません。**

### カナリアリリース（特定コースのみ） {#approve-canary-btn}

シミュレーションした提案を、選択した特定のコースにのみ適用します。スキーマへの追加自体は
システム全体への適用と同じく取り消せませんが、再抽出ジョブの対象を限定して影響を小さく
試せます。

1. 「カナリアリリース（特定コースのみ）」を押すと、コースを選択するための一覧が
   開きます（もう一度押すと閉じます）。

### コースを選択して適用 {#canary-confirm-btn}

カナリアリリースの対象コースを選び、適用します。

1. コース一覧（複数選択可）から、適用したいコースを選びます。
2. 「選択したコースに適用」を押します。

コースを1件も選ばずに押した場合は「適用するコースを選択してください。」と表示され、
何も実行されません。

**「システム全体に適用」「カナリアリリース（特定コースのみ）」が押せない（グレーアウト
している）場合**: 承認処理を実行中です（二重実行を防ぐため一時的に無効になります）。
「承認処理中...」の表示が消えるまでお待ちください。処理が失敗した場合は再び押せる状態に
戻ります。

適用に成功すると「スキーマ提案を承認しました（システム全体 / カナリアリリース）。
再抽出ジョブが開始されます。」と表示され、提案一覧が更新されます（対象の提案は
保留中ではなくなります）。
