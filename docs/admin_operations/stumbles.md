# つまづきデータ（stumbles）タブの操作

「つまづきデータ」タブでは、RAG 検索で教材から回答できなかった学習者の質問
（未回答クエリ）を確認できます。教材の補強やコース改善に使うためのデータであり、
**学習者の評価には使用しません**。

## つまづきデータを確認する {#view}

**対象タブ:** つまづきデータ（stumbles） / **必要ロール:** 教員（TEACHER。そのコースの所有者、
または `editor` 権限を持つ教員）

1. 「つまづきデータ」タブを開き、コース選択プルダウンで対象のコースを選びます。
2. 教材から回答できなかった質問が一覧表示されます（日時・学生・トピック・質問内容）。
   新しい順に、最大 200 件までです。
3. 「更新」ボタンで最新のデータに再読み込みできます。

閲覧できるのは自分が所有する（または編集権限を持つ）コースだけです。権限が無いコースを
指定しても、件数・学生名・質問・日時のいずれも返りません。

### 集計とプライバシー（k-匿名）

この一覧は生の未回答クエリで、学生の表示名と質問文が出ます。**教材の補強・コース改善の
ためだけに使い、学習者の評価には使用しないでください。**

一方、学習者のつまづき・関心に関する**集計ビュー**（原稿スタジオの「つまづき」ペインの
claim 単位サマリーや、関心集約ダッシュボード等）は k-匿名化（k=3）で保護されます。
**該当者が 3 人未満（n<3）のセルは表示されません**。また件数は生の数値ではなく
レンジ（3-5 / 6-10 / 11+）で表示されます。集計ビューから個々の学習者をたどることはできません。
