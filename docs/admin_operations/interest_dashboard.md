# 関心集約（interest-dashboard）の操作

「関心集約」タブでは、学習者の興味関心に基づく集約（つまづき・関心の重なり）を
確認します。

## 橋の候補集約（Phase B）を確認する {#bridge-insights}

**対象タブ:** 関心集約（interest-dashboard） / **必要ロール:** 教員（TEACHER）以上

1. 「関心集約」タブを開きます。
2. 「橋の候補集約」セクションに、個人知識ネットワーク Phase B が導出する「学習者間で
   関心が重なりやすい箇所（橋）」の集約が表示されます。
3. 集約は k-匿名（少人数では該当セルが非表示）で、個別の学習者の履歴は表示されません。
   数値スコアではなく、段階的な事実として提示されます。

この集約は説明改善（どこを重点的に説明し直すか）の材料として使うものであり、個々の
学習者の評価には使いません。
