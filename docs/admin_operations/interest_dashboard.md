# 関心集約（interest-dashboard）の操作

「関心集約」タブでは、学習者の興味関心に基づく集約（つまづき・関心の重なり）を
確認します。

## 橋の候補集約（Phase B）を確認する {#bridge-insights}

**対象タブ:** 関心集約（interest-dashboard） / **必要ロール:** 教員（TEACHER）以上

1. 「関心集約」タブを開き、右上の「コースを選択...」で対象のコースを選びます（上段の
   「関心集約ダッシュボード」と下段の「橋の候補」は同じコース選択に連動します）。
2. 下段の「橋の候補（学習者の重ね合わせ）」に、複数の学習者が自分の引っかかり（tension）を
   同じ構造要素に自分で結び付けた箇所が候補として表示されます。
3. 集約は k-匿名（3名未満の該当セルは非表示）で、個別の学習者の履歴は表示されません。
   人数は生の数値ではなくレンジで、数値スコアではなく段階的な事実として提示されます。
4. 「更新」で読み直します（自動更新はしません）。

この集約は説明改善（どこを重点的に説明し直すか）の材料として使うものであり、個々の
学習者の評価には使いません。
