# AIモデル（llm-models）タブの操作

「AIモデル」タブでは、各場面（コース構築チャット・原稿の書き換え・分野の地図生成など）の
LLM呼び出しに使うモデルの**システム既定**を確認・変更します。**このタブはシステム管理者
（SYSTEM_ADMIN）のみ**が利用できます。教員個人の既定はこのタブでは変更できません
（各教員がそれぞれの画面で設定・解除します）。

このタブの末尾には、教員が URL を指定して教材を取得できるドメインの許可リストもあります
（[URL取得の許可ドメインを管理する](#url-fetch-domains)）。

## 場面別のAIモデル既定を変更する {#change-default}

**対象タブ:** AIモデル（llm-models） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

1. 一覧に各場面の現在のモデルと出所（システム既定 / 環境変数 / 既定値 など）が表示されます。
2. 「変更」を押すと、その場面のカタログ（利用可能なモデルの一覧）から選択できます。
   選択できるのは事前に登録されたモデルのみで、その場面が要求する条件（例: vision 対応）を
   満たさないモデルは選べません。
3. 「保存」を押すと確認ダイアログが表示されます。**この変更は全ユーザーの既定に影響します。**
4. 「既定に戻す」を押すと、そのシステム既定を解除します（未設定の場合はその旨が表示され
   ます）。
5. 「▸ ステージ別に指定する（詳細）」を開くと、解析パイプラインの個別ステージに
   システム既定が設定されている場合のみ、その一覧が表示されます（0件のときはセクション
   自体が表示されません）。行の追加・変更・解除は上記と同じ操作です。
6. 選択の結果は「LLM使用量」タブで確認できます
   （[LLM使用量メトリクスを確認する](llm_usage.md#view-metrics) 参照）。

表示はすべて実際のモデル名です。tier名（fast/standard/deep/analysis）や金額はこのタブには
表示されません。

## URL取得の許可ドメインを管理する {#url-fetch-domains}

**対象タブ:** AIモデル（llm-models） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ
（一覧の参照は教員も可能ですが、追加・削除は管理者だけです）

タブの末尾の「URL取得の許可ドメイン」区画で、教員が URL を指定して教材を取得できるドメインを
管理します。**ここに登録したドメインからのみ取得できます。初期状態は空で、URL 指定の取得と
arXiv からの取り込みは無効です。**

1. 入力欄にドメイン（例: `arxiv.org`）を入れて「追加」を押すと、許可リストに加わります。
2. 一覧の「削除」を押すと確認ダイアログが出ます。確認すると、以後そのドメインからの URL 取得は
   できなくなります。

照合はサーバ側で行われます（画面のボタンが押せるかどうかは補助的な表示です）。教員側の
使い方は [URL を指定して取得する](materials.md#url-upload) と
[arXiv から論文を探して取り込む](materials.md#arxiv-discovery) を参照してください。
