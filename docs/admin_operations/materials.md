# 教材（materials）タブの操作

「教材管理」タブでは、PDF / TeX の教材ファイルをアップロードし、解析パイプラインに
乗せて管理します。各操作の権限は下記のとおりです。

## 教材をアップロードする {#upload}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）以上

1. 「教材管理」タブを開きます。
2. アップロード領域に PDF / TeX ファイルをドラッグ&ドロップするか、領域をクリックして
   ファイルを選びます。
3. アップロードすると解析パイプラインが自動で走り、状態が「処理中 → 完了」と進みます。

アップロード直後は解析待ちのため、しばらくしてから一覧を更新してください。

## 教材の開示範囲を変更する {#visibility}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

教材は次の 3 つの開示範囲を持ちます。

- **public（全体）:** すべてのユーザーに公開されます。
- **group（グループ限定）:** 指定したグループのメンバーだけがアクセスできます。
- **private（自分のみ）:** 作成者本人だけがアクセスできます。

対象の教材を選び、開示範囲を選択して変更します。この操作は後から戻せます。

## 教材を削除する {#delete}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

対象の教材を選び、削除します。**削除は取り消せません。**実行前に確認が入ります。

## 教材の解析コストを見積る {#estimate-cost}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

対象の教材の行にある「解析コスト見積り」ボタンを押すと、解析パイプラインが使う LLM
トークン量の目安をレンジ表示で確認できます。**金額は表示されません**（価格表が設定されて
いても、この見積りはトークン量のレンジのみです）。

## 教材の共有版を発行・削除予約する {#manage-shared-version}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

「版の管理」ボタンを押すと共有版（リリース）モーダルが開きます。これは「共有設定」
（開示範囲・グループ共有）とは別機能です。

1. 「共有版として発行」を押すと、その時点の解析成果を不変の版として発行し、共有先へ
   更新通知が届きます。引用（再利用）はその時点の版に固定されます。
2. 削除予約は猶予期間（既定14日）付きで行え、期限までは「削除予約を取り消す」で取消
   できます。期限を過ぎると物理削除されます。
