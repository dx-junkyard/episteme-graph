# 教材（materials）タブの操作

「教材管理」タブでは、PDF / TeX の教材ファイルをアップロードし、解析パイプラインに
乗せて管理します。各操作の権限は下記のとおりです。

**教材一覧の行に出ているボタンは「パイプラインを実行 ▼」と「⋯」（その他の操作）の 2 つ
だけです。**図・画像、検出要素、グラフレビュー、共有設定、版の管理、位置づけ、近い論文を
探す、ゼミ前ブリーフ、解析コスト見積り、PDF再登録、解析再開、削除は「⋯」メニューの中に
あります（[教材行の「⋯」メニュー](#row-menu) 参照）。

**このタブは教員（TEACHER）向けです。**システム管理者（SYSTEM_ADMIN）でログインすると
教材管理・コース構築・コース管理・原稿スタジオのタブは表示されません。

## 教材をアップロードする {#upload}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）以上

1. 「教材管理」タブを開きます。
2. アップロード領域に PDF または TeX の `.tar.gz`（`.tgz`）をドラッグ＆ドロップするか、
   「ファイルを選択」からファイルを選びます。
3. アップロードすると解析パイプラインが自動で走り、一覧の状態が「処理中 → 完了」と
   進みます。

アップロード領域では、実行前に次の 3 つを指定できます（いずれも任意）。

- **「URLから取得（arXiv など）」**: 手元にファイルが無くても、論文の URL を指定して
  サーバに取得させ、同じ解析パイプラインに流せます（[URL を指定して取得する](#url-upload)）。
- **「図面・画像を解析する（装置図の同定に vision AI を使用）」**: 既定はオフです。
  オンにしたときだけ図画像の vision 解析（装置・パーツ候補の抽出）が実行されます。
- **「解析モデル」**: 解析パイプラインが使う AI モデルの表示と [変更]。押せない場合は
  理由がその場に表示されます。

アップロード直後は解析待ちのため、しばらくしてから「更新」で一覧を読み直してください。
解析が失敗した行には、状態列に「解析を再開」「PDFを再登録」のリンクが出ます。

## URL を指定して取得する {#url-upload}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）以上

アップロード領域の「URLから取得（arXiv など）」を押すとダイアログが開きます（押した時点
では取得しません）。論文の URL（PDF または TeX の `.tar.gz`）を入力して実行すると、サーバが
取得し、ファイルをアップロードした場合とまったく同じ解析パイプラインに合流します。

- **取得できるのは、システム管理者が許可リストに登録したドメインのみです。**
  初期状態の許可リストは空で、この機能は無効です。登録は「AIモデル」タブの
  「URL取得の許可ドメイン」区画で管理者が行います
  （[URL取得の許可ドメインを管理する](llm_models.md#url-fetch-domains) 参照）。
- 許可されていないドメイン・取得できない形式・大きすぎるファイルは、その理由が事実文で
  表示されます。

## 教材の開示範囲を変更する {#visibility}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

教材は次の 3 つの開示範囲を持ちます（現在の値は一覧のタイトル列にバッジで出ます）。

- **公開（誰でも閲覧可）:** すべてのユーザーに公開されます。
- **グループ限定:** 指定したグループのメンバーだけがアクセスできます。
- **非公開（自分のみ）:** 作成者本人だけがアクセスできます。

対象の教材の行で「⋯」→「共有設定…」を押すと「教材の共有・開示範囲」モーダルが開きます。
上段の「開示範囲」で値を選び「適用」を押すと変更されます。この操作は後から戻せます。

同じモーダルの下段では、解析成果をグループ単位で共有できます（グループを選び、
`viewer`（閲覧・引用）または `editor`（編集・再解析）を指定して「追加」）。開示範囲の変更・
グループ共有の付与と解除は、その教材の所有者のみが行えます。

## 教材を削除する {#delete}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

対象の教材の行で「⋯」→「削除…」を押します。**削除は取り消せません。**確認ダイアログでは、
**教材のタイトルを正確に入力しないと「削除する」を押せません**。この教材に紐づくコースも
同時に削除される旨がダイアログに表示されます。

## 教材の解析コストを見積る {#estimate-cost}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

対象の教材の行で「⋯」→「解析コスト見積り…」を押すと、解析パイプラインが使う LLM
トークン量の目安をレンジ表示で確認できます。**金額は表示されません**（価格表が設定されて
いても、この見積りはトークン量のレンジのみです）。

## 教材の共有版を発行・削除予約する {#manage-shared-version}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、自分の教材のみ）

対象の教材の行で「⋯」→「版の管理…」を押すと共有版（リリース）モーダルが開きます。これは
「共有設定」（開示範囲・グループ共有）とは別機能です。

1. 「共有版として発行」を押すと、その時点の解析成果を不変の版として発行し、共有先へ
   更新通知が届きます。引用（再利用）はその時点の版に固定されます。
2. 削除予約は猶予期間（既定14日）付きで行え、期限までは「削除予約を取り消す」で取消
   できます。期限を過ぎると物理削除されます。

## arXiv から論文を探して取り込む {#arxiv-discovery}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）以上

分野の条件（arXiv カテゴリ・キーフレーズ・著者）で arXiv を検索し、候補の一覧から選んだ論文
だけを教材として取り込みます。**候補を並べるところまでが自動で、解析パイプラインに入るのは
教員が選んで実行した論文だけです。** 条件に合う論文が自動で取り込まれることはありません。

1. 「教材管理」タブのアップロード領域にある「arXivから探す」を押し、モーダルを開きます。
2. 分野を選び（または入力し）、arXiv カテゴリとキーフレーズを指定します。キーフレーズは
   分野の地図の概念・カートリッジ語彙・承認済みの理論部品・教員が確定した別名から候補が
   供給され、各チップにその出所が表示されます。クリックで外せます（外したものも「使わない」
   状態で残ります）。「著者フォロー（任意）」に著者名を追加すると、その著者の論文も条件に
   加わります。カテゴリ・キーフレーズ・著者はそれぞれのグループ内では「いずれか」、
   グループ同士は「かつ」で組み合わされます。
3. 「この条件で検索」を押すと候補が一覧されます。この検索では AI（LLM）を使いません。
   一覧の上には使われた検索条件と、実際に適用された並び順が常に表示されます。
   **この一覧は検索条件に一致した範囲のみで、その分野の論文の全体ではありません。**
   「並び順」を「関連度順」にすると、次の検索から、その分野で既に取り込んだ論文との近さの
   目安で並べ替えられ、各候補に「関連: 高 / 中 / 低」の段階ラベルが付きます（数値は表示
   されず、候補が絞り込まれることもありません）。並べ替えられなかったときは新着順のまま
   その理由が表示されます。
4. 取り込む論文にチェックを入れ、「選択した論文を取り込む」を押します。5件までならその場で
   取得と解析が始まります。6件以上を選んだときは取り込みキューへの登録になり（一度に登録
   できるのは50件まで）、サーバが1件ずつ・間隔をあけて順に取得・解析します。押す前に、
   どちらの経路で何が起きるかが事実文で表示されます。取り込み後は、ファイルを選んで
   アップロードした場合とまったく同じ解析パイプラインが走り、進捗は教材一覧に表示されます。
5. キューに登録した項目の状態（待機中 / 取得中 / 受理済み / 失敗）は、モーダル内の
   「取り込みキュー」欄で確認します。**この欄は自動では更新されません**（「更新」ボタンを
   押して読み直します）。失敗した行は消えず、理由が表示され、「再試行」でその項目だけを
   待機中に戻せます。
6. 条件を再利用するときは「この条件を保存」を押します。購読条件は分野ごとに1つの共同の
   設定で、同じ分野を扱う他の教員も同じ条件を読み込みます。

取り込みには、システム管理者が取得先ドメインとして `arxiv.org` を許可している必要があり
ます（「URLから取得」と同じ許可リストです）。未登録の場合、検索と閲覧は
できますが取り込みボタンは無効になり、理由が表示されます。

興味のない候補は「見送る」で一覧から外せます。見送りは記録として残り、「見送り済みを表示」
から「戻す」で候補に戻せます。

条件による検索とは別に、「引用グラフから探す」で、その分野で既に取り込んだ論文を起点に
引用・推薦の関係でつながる論文を候補として並べることもできます（一覧には出所と「引用元」が
常に示され、取り込みは同じく教員の明示操作です）。この供給源はサーバ環境変数
`DISCOVERY_CITATION_SOURCE_ENABLED` による任意設定で既定は無効なため、無効のときはボタンが
押せず理由が表示されます（有効化はシステム管理者に依頼します）。

モーダルの検索・購読パネルの下には、学習者が「論文の海」で地図の端を開いて「この先を
知りたい」を押した記録の集計が、**人数の範囲だけの事実行**として出ることがあります
（行が無ければ区画ごと表示されません）。これは需要の提示であって、検索条件・取り込み・
分野の地図を自動で変えることはありません。

## この論文に近い論文を探す（論文レーダー） {#paper-radar}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）以上

すでに取り込んだ教材（論文）を**起点**に、距離を選んで arXiv から他の論文を探します。
分野の条件で網を張る[arXiv から論文を探して取り込む](#arxiv-discovery) に対して、こちらは
1本の論文から周辺を照らす探し方です。**候補を並べるところまでが自動で、解析パイプラインに
入るのは教員が選んで実行した論文だけです。**

1. 「教材管理」タブで起点にしたい教材の行の「⋯」メニューを開き、「📡 近い論文を探す…」を
   選びます（解析済みで document_id が付与された教材にのみ表示されます）。
2. 距離を選びます。「近い」（分野もテーマも近い）/「中間」（テーマが部分的に重なる）/
   「同じ分野の別テーマ」（同じカテゴリでテーマが離れている）の3つです。既定は「近い」で、
   このときだけキーフレーズによる絞り込みが使われます。
3. 検索条件（arXiv カテゴリ・キーフレーズ）を確認します。起点の教材の arXiv メタデータ、
   または教材が属する分野の購読条件から供給されます。どちらも引けない場合（手元のファイル
   からアップロードした教材など）はカテゴリを自分で入力します。**ここで変えた条件は保存
   されません**（分野の購読条件は書き換わりません）。
4. 「この条件で検索」を押すと候補が一覧されます。この検索では文章生成 AI（LLM）を使い
   ません。各候補には「距離: 近い / 中間 / 遠い」の段階ラベルだけが付き、数値は表示され
   ません。選んだ距離以外の候補も折りたたみとして残ります。距離を測れなかった候補は
   ラベルを付けず別区画に分けて表示されます。一覧の上には使われた検索条件と、
   **この一覧が検索条件に一致した範囲のみである**旨の注記が常に表示されます。
5. 必要なら、候補にチェックを入れて「違いを分析」を押します（一度に10件まで）。起点の
   論文との共通点と違いが、候補の要旨からの逐語引用付きで各候補カードに表示されます。
   これは**アブストラクトの比較に基づく AI の推定**で、本文は確認されていません。結果は
   保存されず、モーダルを閉じると消えます。日次上限に達した場合は、その旨が表示され翌日
   以降に実行できます。
6. 取り込む論文にチェックを入れ、「選択した論文を取り込む」を押します。5件までならその場で
   取得と解析が始まり、6件以上は取り込みキューへの登録になります（一度に50件まで）。
   取り込みの仕組み・進捗の確認方法は[arXiv から論文を探して取り込む](#arxiv-discovery)
   とまったく同じです。

取り込みには、システム管理者が取得先ドメインとして `arxiv.org` を許可している必要があり
ます（「URLから取得」「arXivから探す」と同じ許可リストです）。未登録の場合、検索・閲覧・
比較分析はできますが取り込みボタンは無効になり、理由が表示されます。

この画面から分野の購読条件・見送りの記録・分野の地図が変わることはありません。学習者向けの
表示もありません。

## 論文の議論のきっかけ（AI候補）を確認する {#discuss-opening-review}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）

学習者が「この論文と議論する」を開いたときに出す「議論のきっかけ」は、AI が論文から作った
候補です。**承認するまで学習者には表示されません。**

1. 対象の教材の行で「⋯」→「検出要素」を押して要素の一覧を開きます。
2. 「説明レビュー（件数）」を押すとレビューキューが開きます。先頭のグループが
   「この論文の議論のきっかけ」です（候補が無いときはボタンが押せません）。
3. 各候補は [承認] [却下] で判断します。文面を直したいときは「本文を編集」→「本文を保存」で
   その場で書き換えられます。まとめて処理したいときは選択して「選択したN件を承認 / 却下」を
   使います（実行前に確認が出ます）。
4. 承認後に元の解析結果が変わった場合は、その候補に鮮度の注記が付いてキューに戻ります
   （承認が自動で外れることはありません）。

## 図・画像の分類を確認する {#review-figures}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）

教材から抽出された図・画像には、AI による分類の候補（機能構成図 / グラフ / 写真・解説画像 /
混在 / 不明）が付きます。AI の分類は**教員が確認するまで候補のまま**で、確定はしません。

1. 「教材管理」タブで対象の教材の行の「⋯」→「図・画像」を押し、図モーダルを開きます。
   各図のサムネイル・キャプション・抽出方法と、装置候補（図面・画像の解析を有効にして
   解析した場合）が一覧されます。
2. 図ごとの「深く検討」を押すと要素検討モーダルが開きます。上部に現在の分類（AI候補には
   「AI候補・要確認」、確定済みには「教員確認済み」の表示）と理由が出ます。
3. 「表示分類」で分類を選び「保存」を押すと確定します。選び直せば訂正でき、「AI候補に戻す」
   で確定を取り消せます。教員の指示を添えて「AIで図を再解析」することもできます
   （再解析の結果も候補です）。
4. 確定済みの分類は、再解析で AI 候補が更新されても上書きされません（レビュー結果と
   AI 候補は別に保持されます）。
5. 装置候補は「図で確認」で図上の位置を確認でき、「ライブラリへ昇格」でナレッジライブラリの
   エントリにできます（[エントリを参照・凍結する](library.md#view-and-freeze) 参照）。

未確認の分類が残っている教材は、「次にやること」パネルに事実として表示されます
（確認が済めば項目は自動で消えます）。

## 教材行の「⋯」メニュー {#row-menu}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER）

一覧の行に常に出ているのは「パイプラインを実行 ▼」と「⋯」の 2 つだけです。「⋯」を押すと
次の操作が出ます（解析済みで document_id が付与された教材にのみ出る項目があります）。

- **図・画像**: 抽出された図・画像と装置候補の一覧（[図・画像の分類を確認する](#review-figures)）。
- **検出要素**: この教材からパイプラインが検出した理論部品・主張・数式・図の一覧。ここから
  各要素の「深く検討」や、AI が用意した「議論のきっかけ」の「説明レビュー」に入れます
  （[論文の議論のきっかけ（AI候補）を確認する](#discuss-opening-review)）。
- **🕸 グラフレビュー…**: 理論操作グラフを見ながら AI と対話し、論理要素・主張を承認・却下
  する画面（[グラフを見ながら確認・承認する](#graph-review)）。
- **共有設定…**: 開示範囲とグループ共有（[教材の開示範囲を変更する](#visibility)）。
- **版の管理…**: 共有版の発行・削除予約（[教材の共有版を発行・削除予約する](#manage-shared-version)）。
- **位置づけ（分野マップ）…**: この論文が分野マップのどこに位置づくかの AI 候補を確認・
  却下・再検討する（[論文の位置づけを確認する](#landscape)）。
- **📡 近い論文を探す…**: [この論文に近い論文を探す（論文レーダー）](#paper-radar)。
- **ゼミ前ブリーフ…**: 輪講の前に、この論文の脆い前提・支持のしかた・確かめられていない
  ところを確認する読み取り専用のビュー（この画面から確定操作はできません）。
- **解析コスト見積り…**: [教材の解析コストを見積る](#estimate-cost)。
- **PDF再登録** / **解析再開**: 解析に失敗した教材の復旧。同じ操作は失敗行の状態列にも
  リンクとして出ます。
- **削除…**: [教材を削除する](#delete)。

「パイプラインを実行 ▼」からは、解析パイプラインの全実行と、個別ステージだけの再実行を
選べます。

## グラフを見ながら確認・承認する {#graph-review}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER。承認・却下は編集権限が
必要です。閲覧権限だけの場合は見ることと AI との対話までです）

対象の教材の行で「⋯」→「🕸 グラフレビュー…」を押すと、理論操作グラフを見取り図にした
レビュー画面が開きます。**承認・却下はすべて教員の操作で、AI との対話から承認が実行される
ことはありません。**

1. 左側にグラフが出ます。層（主グラフ / 式の詳細 / すべて（デバッグ））を切り替えられ
   （層が 1 つだけのグラフでは切り替えは出ません）、「未レビューのみ強調」「次の未レビューへ」で
   確認すべきノードをたどれます。
2. ノードを選ぶと詳細が出ます。ここで論理要素（component）の [承認] [却下] と、その根拠に
   なっている主張（claim）の承認ができます。要素の内訳をさらに見たいときは「深く検討」で
   要素検討モーダルに移れます。**複数の要素をまとめた表示用のノードでは承認・却下はできません**
   （その場合はまとめ元の式の詳細層のノードや根拠 claim で行うよう案内が出ます）。根拠 claim の
   うち解析結果から読み出したものは「未承認（解析結果）」と表示され、元になった主張がある場合は
   「元の主張を承認」から承認できます。
3. チャットは「このノードについて」と「グラフ全体について」の 2 つがあります。AI の応答は
   確認の材料であって承認ではありません。マイクのアイコンから音声で対話することもできます。
4. 「表示: グラフ | 論文の順」を切り替えると、章立て・式番号・図番号といった論文の並びで
   同じ内容を確認できます。

グラフがまだ構築されていない教材ではこの画面は使えません（その旨が表示されます）。

## 論文の位置づけを確認する {#landscape}

**対象タブ:** 教材管理（materials） / **必要ロール:** 教員（TEACHER、閲覧できる教材。確認・
却下は編集権限が必要です）

対象の教材の行で「⋯」→「位置づけ（分野マップ）…」を押すと、この論文が分野マップ（骨格）の
どのアンカーに位置づくかの候補が分野ごとに表示されます。**AI が出したものは「AIによる推定
（未確認）」のままで、確定は教員の操作だけです。**

- 各候補は [確認][却下][再検討] で状態を変えられます。却下した候補を AI が再提案で復活させる
  ことはありません。
- 「AIで再提案」で候補を作り直せます（日次の上限に達している場合・素材や骨格が無い場合は、
  その理由が事実文で表示されます）。
- どこにも置けなかった分野は「配置できなかった」ことがそのまま理由付きで表示されます。
  これは失敗ではなく、分野マップを育てる材料になります（分野マップ側の候補としてまとめて
  レビューします）。

コースを公開する前にまとめて確認したい場合は、コース管理の「確認して公開」からも同じ配置を
確認できます（[リリース前に確認して公開する](course.md#release-review) 参照）。
