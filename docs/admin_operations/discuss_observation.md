# discuss 観測（discuss-observation）タブの操作

「discuss 観測」タブでは、「論文と話す」（discuss）モードの Phase 3（v2）着手判断のための
観測データを確認します。**このタブはシステム管理者（SYSTEM_ADMIN）のみ**が利用できます。
表示はすべて参考目安であり、達成しても自動的に何かが実行されることはありません。

## discuss 観測データを確認・ダンプする {#view-and-dump}

**対象タブ:** discuss 観測（discuss-observation） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

1. 「取得」を押すと、以下が表示されます。
   - LLM利用量（discuss / casual / 通常チャットのタグ別の件数・ユーザー数・期間）
   - discuss 痕跡（会話ターン）の grounding 分布（教材由来 / 別の資料 / AI生成）
   - UI イベント件数（開幕・着地・分岐チップ等）
   - 分析開始の参考目安（各項目の現状・目安・達成有無）
2. 参考目安の達成状況は表示のみです。**達成しても自動的に何かが実行されることはありません**
   （Phase 3 着手の判断は運用者が行います）。
3. 「ダンプ (tar.gz)」または「ダンプ (zip)」を押すと、観測データのアーカイブが
   ダウンロードされます。

このタブは自動更新（ポーリング）しません。最新の状況は「取得」ボタンで手動更新して
ください。
