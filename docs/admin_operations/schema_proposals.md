# スキーマ提案（schema-proposals）タブの操作

「スキーマ提案」タブでは、未回答クエリの分析から AI が提案したスキーマ拡張
（新しい概念タイプ・述語）を、シミュレーション（Shadow Testing）で検証してから
承認・却下できます。提案は承認されるまでシステムに反映されません。

## スキーマ提案を確認・承認する {#review}

**対象タブ:** スキーマ提案（schema-proposals） / **必要ロール:** 教員（TEACHER）

1. 「スキーマ提案」タブを開くと、提案の一覧が表示されます。
2. 提案の「シミュレーションを実行」を押すと、既存教材への影響（マッチ件数・適用例）が
   「シミュレーション結果」に表示されます。
3. 結果を確認のうえ、承認アクションを選びます。
   - **システム全体に適用**: 全教材の再抽出ジョブを開始します。**取り消せないため、
     実行前に確認ダイアログが入ります。**
   - **カナリアリリース（特定コースのみ）**: コースを選び「選択したコースに適用」を押すと、
     そのコースだけに適用して影響を限定して試せます。
4. 不要な提案は却下できます。

**このタブに提案を新しく生成するボタンはありません。** 提案が 1 件も無い場合は、
「DSL進化分析」タブで「AIメタ分析を実行」を押して生成します
（[DSL進化分析を実行する](schema.md#analyze) 参照）。
