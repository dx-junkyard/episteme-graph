# 教員管理（teachers）タブの操作

「教員管理」タブでは、教員アカウントを新規作成します。**このタブと作成操作はシステム
管理者（SYSTEM_ADMIN）のみ**が利用できます（教員のロールでは表示されません）。

## 教員アカウントを作成する {#create-teacher}

**対象タブ:** 教員管理（teachers） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

1. 「教員管理」タブを開きます（システム管理者にのみ表示されます）。
2. ユーザー名・メールアドレス（任意、未入力時は自動生成）・パスワードを入力し、
   「教員を作成」を押します。
3. 送信すると即座に作成が実行されます。**確認ダイアログは表示されません**（ユーザー名と
   パスワードの入力必須チェックのみです）。**アカウント作成は取り消せません**（削除 API は
   ありません）。入力内容をよく確認してから送信してください。
4. ユーザー名が既に使用されている場合はエラーメッセージが表示されます。
