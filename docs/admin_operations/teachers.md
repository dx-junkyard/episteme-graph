# 教員管理（teachers）タブの操作

「教員管理」タブでは、教員アカウントを新規作成し、教員・管理者アカウントを一覧・運用します
（一覧・停止・パスワード再設定・削除予約・移管の手順は
[アカウントを一覧する](users.md#list-users) 以降を参照してください）。
**このタブと、ここでの操作はシステム管理者（SYSTEM_ADMIN）のみ**が利用できます
（教員のロールでは表示されません）。

## 教員アカウントを作成する {#create-teacher}

**対象タブ:** 教員管理（teachers） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

1. 「教員管理」タブを開きます（システム管理者にのみ表示されます）。
2. ユーザー名・メールアドレス（任意、未入力時は `ユーザー名@learning.local` が使われます）・
   パスワードを入力し、「教員を作成」を押します。
3. 送信すると即座に作成が実行されます。**確認ダイアログは表示されません**（ユーザー名と
   パスワードの入力必須チェックのみです）。入力内容をよく確認してから送信してください。
4. ユーザー名またはメールアドレスが既に使われている場合はエラーメッセージが表示されます。

作成したアカウントの行は消せません。使わなくなったアカウントは、停止（
[教員アカウントを停止する](users.md#suspend-teacher)）と削除予約（
[アカウントの削除を予約する](users.md#schedule-deletion)）で運用します。教材・コース・
グループを所有したままでは削除できないため、先に
[所有物を別の教員へ移管する](users.md#transfer-ownership) を行ってください。
