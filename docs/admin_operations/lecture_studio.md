# 原稿スタジオ（lecture-studio）の操作

「原稿スタジオ」タブでは、チャンクやトピックのレクチャー原稿を編集し、AI に書き換えを
依頼できます。上部でコースを選ぶと編集画面が開きます。コース単位の操作（設定・コース内容
生成・音声生成）は右上の「コース設定 ▼」メニューにあります。

## チャンクの原稿を AI で書き換える {#rewrite-chunk}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER。その教材を編集
できる権限が必要です）

1. 「原稿スタジオ」タブを開き、コースを選び、左のリストから対象のチャンク（トピック）を
   選びます。
2. ツールバーの「AI で書き換え」を押すとモーダルが開きます。「書き換え指示」に指示（例:
   「もっとやさしい言い回しに」「式の意味を一言添えて」）を入力し、「AIで提案」を押します。
   この実行に使う AI モデルはモーダル内の「生成モデル」で切り替えられます。
3. AI が新しい原稿（表示テキスト・読み上げテキスト・数式）を生成し、**その場で保存
   されます**。原稿が変わるため、そのチャンクの既存音声キャッシュは無効化されます
   （音声は再生成が必要になります）。

「論理要素」ビューで実行した場合だけは例外で、結果は保存されず、論理要素の候補として画面に
反映されます（採否は教員が行います）。

操作アシスタント（Copilot）経由で実行した場合は、実行前の原稿がスナップショット
として保存され、「戻す」で書き換え前の状態に復元できます（復元時も音声キャッシュは
無効化されます）。

## コース原稿の音声を生成する {#audio}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

1. 対象のコースを選び、右上の「コース設定 ▼」→「音声生成…」を押します（押した時点では
   生成しません。ダイアログが開きます）。
2. 「読み上げ言語」（日本語 / English）を選びます。現状の生成済みスライド数が表示されます。
   コースの設定言語と違う言語を選んだ場合は、**読み上げ原稿を作り直してから音声を作り直す**
   こと・既存の音声が使われなくなることが事前に警告されます。
3. 「生成を開始」を押すと、スライド単位で音声を生成します。すでに同じ言語の音声があるスライドは
   作り直しません。

**「音声生成…」が押せないときは、その理由と次の操作がメニュー内に表示されます。** 主な理由は、
コースを選んでいない / コース内容がまだ生成されていない / 読み上げ原稿が未生成のチャンクが
残っている / 別の処理が進行中、です。読み上げ原稿を先に用意してから実行してください。

トピックの授業用教材・読み上げ原稿を編集すると、そのトピックの音声は無効化されます（保存前に
その旨が表示されます）。学習者側の画面から音声が生成されることはありません（配信されるのは
ここで作った音声だけです）。

## 再構成レビューキューを確認する {#review-queue}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

再構成ループ（R層）は claim を出題（ELICIT）に自動変換して学習者に配信します。教員は
事後の監査役として、疑わしさランク順のレビューキューを確認できます。

1. 「原稿スタジオ」タブで対象のコースを選びます。
2. 「コース」ビューまたは「コンポーネント」ビューの見出し行にある「再構成の確認（要レビュー
   N件）」ボタンを押すと、レビューキューが開きます。
3. 各 item を確認し、`confirmed`（追認）/ `flagged`（要修正）/ `retired`（回収）へ状態遷移
   できます。削除 API はありません（行は必ず状態遷移で保持されます）。

## 同一性リンクを確定する・標準化度を評価する {#identity-links-standardization}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

要素検討ワークスペース（W層）の「深く検討」モーダルには、その要素が別の資料・共通部品
（shared_part）と同じものだという対応づけ（同一性リンク）のセクションがあります。

1. 主張・論理要素のカード（「主張」「論理要素」ビュー）や、根拠リンクの要素カードにある
   「深く検討」ボタンを押してモーダルを開きます。教材管理タブの図モーダルからも同じ
   モーダルを開けます。
2. 「同一性リンク」セクションに候補（candidate）・確定（confirmed）・却下（rejected）が
   区別して表示されます。候補には「確定」「却下」ボタンがあります。既存の表記は書き換え
   られず、リンクの追加のみが行われます。
3. 対象が共通部品（shared_part）の場合のみ、「標準化度を評価」ボタンが追加で表示されます。
   評価は三角測量（LLM 事前知識・ライブラリ内の類似・コーパス内の反復）による候補で、
   確定は対話ペイン下の候補カードから教員が行います（自動では確定しません）。

## AI と対話して説明図を作る（教材図スタジオ） {#figure-studio}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコース。
閲覧・一覧は編集権限を共有された教員も可）

教材のわかりづらい箇所に、AI と対話して説明図（SVG）を作り、本文に埋め込めます。

1. コースを選び、トピックの「授業用教材」欄を開きます。図を入れたい位置にカーソルを置いて、
   欄の上の「🖼 図を挿入」を押します。
2. モーダルが開きます。「既存の図から選ぶ」ではこのコースで作った図を選べます。新しく作る
   場合は、どんな図がほしいかを書いて送信すると、AI が図の案を返します。会話を続けて直して
   いきます（毎回、図の全体が作り直されます）。
3. 「採用して挿入」を押すと、`![[figure:id]]` の形でカーソル位置に挿入され、同時にこの
   トピックの図として登録されます。**採用は教員の操作で、AI が本文を書き換えることは
   ありません。**
4. 採用した図はキャプションの変更や、配信からの回収（retire）ができます。回収した図は
   削除されず、学習者側では「配信対象ではありません」と表示されます。

右ペインの「図の提案」には、つまづきの集約などから「図があると分かりやすいかもしれない
箇所」の候補が出ます。候補は候補のままで、作るかどうかは教員が決めます。

**「🖼 図を挿入」が押せない場合:** 読み上げ原稿の欄にフォーカスしていると無効になります
（図は読み上げから除かれるため、挿入先は授業用教材の欄だけです）。授業用教材の欄をクリック
してから押してください。トピックを開いていない場合はボタン自体が出ません。

図を挿入すると、その分だけ表示のページ分割が変わることがあります（図 1 個をおよそ 200 字と
数えます）。トピックを保存すると、そのトピックの音声キャッシュは作り直しになります。
