# 原稿スタジオ（lecture-studio）の操作

「原稿スタジオ」タブでは、チャンクやトピックのレクチャー原稿を編集し、AI に書き換えを
依頼できます。

## チャンクの原稿を AI で書き換える {#rewrite-chunk}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

1. 「原稿スタジオ」タブを開き、左のリストから対象のチャンクを選びます。
2. AI アシスタントを開き、書き換えの指示（例: 「もっとやさしい言い回しに」「式の意味を
   一言添えて」）を入力します。
3. AI が新しい原稿案を返し、エディタに反映されます。**この時点ではまだ保存されていません。**
   気に入らなければ戻せます。
4. 問題なければ保存して確定します。

書き換えは保存前のエディタ反映なので、確定するまで何度でもやり直せます。

## コース原稿の音声を生成する {#audio}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

対象のコースを選び、音声生成を実行します。原稿（spoken_text）が生成済みのチャンクを
対象に TTS 音声を作成し、`lecture_audio_cache` に保存します。すでに音声があるチャンクは
再生成をスキップします。
