# 原稿スタジオ（lecture-studio）の操作

「原稿スタジオ」タブでは、チャンクやトピックのレクチャー原稿を編集し、AI に書き換えを
依頼できます。

## チャンクの原稿を AI で書き換える {#rewrite-chunk}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

1. 「原稿スタジオ」タブを開き、左のリストから対象のチャンクを選びます。
2. AI アシスタントを開き、書き換えの指示（例: 「もっとやさしい言い回しに」「式の意味を
   一言添えて」）を入力します。
3. AI が新しい原稿案を返し、エディタに反映されます。**この時点ではまだ保存されていません。**
   気に入らなければ戻せます。
4. 問題なければ保存して確定します。

書き換えは保存前のエディタ反映なので、確定するまで何度でもやり直せます。

## コース原稿の音声を生成する {#audio}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

対象のコースを選び、音声生成を実行します。原稿（spoken_text）が生成済みのチャンクを
対象に TTS 音声を作成し、`lecture_audio_cache` に保存します。すでに音声があるチャンクは
再生成をスキップします。

## 再構成レビューキューを確認する {#review-queue}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

再構成ループ（R層）は claim を出題（ELICIT）に自動変換して学習者に配信します。教員は
事後の監査役として、疑わしさランク順のレビューキューを確認できます。

1. 「原稿スタジオ」タブで対象のコースを選びます。
2. コース/コンポーネントビュー付近の「再構成の確認」ボタン（未レビュー件数が表示されます）
   を押すと、レビューキューが開きます。
3. 各 item を確認し、`confirmed`（追認）/ `flagged`（要修正）/ `retired`（回収）へ状態遷移
   できます。削除 API はありません（行は必ず状態遷移で保持されます）。

## 同一性リンクを確定する・標準化度を評価する {#identity-links-standardization}

**対象タブ:** 原稿スタジオ（lecture-studio） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

要素検討ワークスペース（W層）の「深く検討」モーダルには、その要素が別の資料・共通部品
（shared_part）と同じものだという対応づけ（同一性リンク）のセクションがあります。

1. claim / component カードなどの「深く検討」ボタンを押してモーダルを開きます。
2. 「同一性リンク」セクションに候補（candidate）・確定（confirmed）・却下（rejected）が
   区別して表示されます。候補には「確定」「却下」ボタンがあります。既存の表記は書き換え
   られず、リンクの追加のみが行われます。
3. 対象が共通部品（shared_part）の場合のみ、「標準化度を評価」ボタンが追加で表示されます。
   評価は三角測量（LLM 事前知識・ライブラリ内の類似・コーパス内の反復）による候補で、
   確定は対話ペイン下の候補カードから教員が行います（自動では確定しません）。
