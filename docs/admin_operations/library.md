# ナレッジライブラリ（L層 / knowledge-library）の操作

「ナレッジライブラリ」タブでは、分野（domain）ごとの装置・パーツ・理論コンポーネントの
共同財（library entries）を参照・編集・凍結します。パイプライン（装置図理解パイプライン等）
が実際に参照するのは**凍結版のみ**で、draft は参照されません。

## エントリを参照・凍結する {#view-and-freeze}

**対象タブ:** ナレッジライブラリ（knowledge-library） / **必要ロール:** 教員（TEACHER）以上

1. 「ナレッジライブラリ」タブを開き、左の分野一覧から分野を選びます。
2. エントリ一覧から参照したいエントリを選ぶと、詳細（本文・出典・凍結版履歴）が表示
   されます。一覧は名称・別名での検索と種別（装置 / 理論コンポーネント）での絞り込みが
   でき、「廃止済みも表示」で廃止したエントリも確認できます。新しいエントリは右上の
   「新規エントリ作成」から作れます（教材の図モーダルの装置候補から「ライブラリへ昇格」
   することもできます）。
3. draft の内容を編集して保存できます（`expected_revision` による楽観ロック。他の教員が
   先に更新していた場合は 409 になり、再読み込みが必要です）。
4. 内容が固まったら「凍結（版発行）」を押すと、その時点の内容が凍結版として追加され、
   以降パイプラインの参照対象になります。
5. 使わなくなったエントリは「廃止」で `retired` 状態にできます（行削除はしません。廃止済み
   エントリは以後の参照検索に出ません）。**廃止済みのエントリは読み取り専用です**（編集・
   凍結はできません）。「復元」で戻してから編集してください。
6. エントリの詳細から「深く検討」を押すと、共通部品として要素検討モーダルを開けます
   （同一性リンクの確定・標準化度の評価は
   [同一性リンクを確定する・標準化度を評価する](lecture_studio.md#identity-links-standardization)
   参照）。

例示画像を含めるかどうかは、元 document の所有者のみが明示的に選択でき、それ以外の教員が
画像を含めようとすると拒否されます（エントリ本文のテキストは教員全体に開示されます）。
