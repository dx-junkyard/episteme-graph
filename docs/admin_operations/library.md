# ナレッジライブラリの操作

「ナレッジライブラリ」タブでは、分野ごとの装置・パーツ・理論の部品・概念のエントリを
参照・編集・凍結し、論文どうしで同じものを結び付けます。教材の解析が参照するのは
**凍結した版だけ**で、編集中の内容は参照されません。

## エントリを参照・凍結する {#view-and-freeze}

**対象タブ:** ナレッジライブラリ / **必要な役割:** 教員以上

1. 「ナレッジライブラリ」タブを開き、左の分野一覧から分野を選びます。
2. エントリ一覧から参照したいエントリを選ぶと、詳細（本文・出典・凍結版の履歴）が表示
   されます。一覧は名称・別名での検索と種別での絞り込みができ、「廃止済みも表示」で
   廃止したエントリも確認できます。新しいエントリは右上の「新規エントリ作成」から作れます
   （教材の図の画面の装置候補から「ライブラリへ昇格」することもできます）。
3. 詳細の内容を編集して保存できます。ほかの教員が先に保存していた場合は「他の教員が
   更新しました。再読み込みしてください」と表示されるので、読み込み直してから編集し直してください。
4. 内容が固まったら「凍結（版発行）」を押すと、その時点の内容が凍結版として追加され、
   以降の教材の解析が参照します。
5. 使わなくなったエントリは「廃止」にできます（消えはしません。廃止したエントリは以後の
   参照検索に出ません）。**廃止したエントリは読み取り専用です**（編集・凍結はできません）。
   「復元」で戻してから編集してください。
6. エントリの詳細から「深く検討」を押すと、共通部品として要素検討の画面を開けます
   （同一性リンクの確定・標準化度の評価は
   [同一性リンクを確定する・標準化度を評価する](lecture_studio.md#identity-links-standardization)
   参照）。

例示画像を含めるかどうかは、元の教材の所有者だけが明示的に選べ、それ以外の教員が
画像を含めようとすると拒否されます（エントリ本文のテキストは教員全体に開示されます）。

## 同一性の候補を確認する・見送る {#identity-candidates}

**対象タブ:** ナレッジライブラリ / **必要な役割:** 教員以上

1. タブ上部の「同一性の候補」に、教材の解析が見つけた「ほかの論文の部品と同じもの」の
   候補が、支持する論文の題名と一緒に並びます。
2. 候補ごとに「確認」か「見送り」を押します。確認した結び付きだけが、学生の画面の
   部品の文脈に「教員がこの部品と同じものとして確かめた共通部品」として現れます
   （くわしくは [確定すると学生に何が見えるか](#what-students-see)）。見送った候補は消えず、
   同じ組み合わせは再提案されません。
3. 候補が無いときは、その事実と、候補がどこで作られるかが表示されます。候補は教材の解析の
   最後の段（共通する概念の候補づくり）で、ほかの論文の部品や登録済みのエントリと名前・構造が
   一致したときに作られます。教材を追加したあとは、教材管理の行の「パイプラインを実行 ▼」から
   「共通する概念の候補づくり」を実行し直すと、改めて探します。
4. 候補が無いときの表示は、**探して無かった**のか、**まだ探していない**のかを言い分けます。
   候補づくりの規則が足されたあと、その規則でまだ探していない教材があれば、その題名と
   「パイプラインを実行 ▼」から探し直す道が出ます。閲覧できる解析済みの教材をすべていまの
   規則で探したときは「すべていまの規則で探しました」と出ます。

## 確定すると学生に何が見えるか {#what-students-see}

**対象タブ:** ナレッジライブラリ / **必要な役割:** 教員以上

確定・凍結の操作ごとに、学生の画面に届くものが違います。

- **同一性の候補・同一性リンクを確定する**（この部品とこの共通部品は同じもの）:
  学生が部品の文脈を開くと「教員がこの部品と同じものとして確かめた共通部品」として
  共通部品の名前と説明が出ます。**学生に出る名前と説明は、そのエントリの凍結した版の
  ものです。凍結していないエントリ（凍結版が 1 つも無いもの）は、確定していても学生には
  出ません**（下書きの編集は凍結するまで学生に届きません）。標準化度の評価は、教員が
  評価を確定したときだけ一文で出ます（未評価は学生に何も出ません）。同じ共通部品に確定済みで結ばれたほかの論文のうち、
  その学生が読める論文の題名も並びます。学習チャットでその部品を選んで質問すると、
  回答の前提にも「教員が同じものとして確かめている」事実が入ります。部品が共通部品を
  使う・満たすだけの関係（たとえば方程式を満たすように作ったネットワーク）は同じもの
  ではないので確定しないでください。
- **見送る**: 学生の画面には何も出ません。見送った組み合わせは再提案されません。
- **エントリを凍結する**: 教材の解析（以後の解析が参照する照合の材料）に使われ、確定した
  結び付きがあるときは、学生の「共通部品として」に出る名前と説明もこの凍結版になります。
  凍結しないうちは、確定した結び付きがあっても学生には出ません。
- **確定を取り消す**: エントリの詳細の「結びついた教材の部品」（または部品の「深く検討」の
  同一性リンク区画）で、確定の行の「確定を取り消す」を押し、理由を書きます。その結び付きは
  学生の画面から消えます（[確定した結び付きを取り消す](#revoke-identity-link)）。
- **別名・隠しラベル・関係・地図との対応**: 照合と検索の材料になります。学生の画面に
  そのまま並ぶことはありません。

## 確定した結び付きを取り消す {#revoke-identity-link}

**対象タブ:** ナレッジライブラリ / 要素検討（深く検討） / **必要な役割:** 教員以上（その部品の論文を編集できる教員）

誤って確定した同一性リンク（たとえば、共通部品を使う・満たすだけの部品を同じものとして
確定した）は取り消せます。

1. ナレッジライブラリでエントリを選び、詳細の「結びついた教材の部品」で確定の行を探します
   （部品の「深く検討」の「同一性リンク」区画からも同じ操作ができます）。
2. 行の「確定を取り消す」を押し、取り消す理由を書きます（理由は必須です）。
3. 行は「確定を取り消し」になり、学生の画面の「共通部品として」から消えます。行は消えず、
   誰が確定したか・誰がいつ・なぜ取り消したかが記録に残ります。

確定した行には作成者と確定者が表示名で出ます。作成者が自分で確定したときは
「作成者が確定しました。」と書かれます（自分で確定することは禁じていません）。

## 見送った・取り消した結び付きを候補に戻す {#restore-identity-link}

見送った（却下した）結び付きと、確定を取り消した結び付きは、判断を誤ったときに候補に戻せます。
同じ組の行は作り直せず、候補づくりを走らせ直しても同じ組は提案されないので、戻す手はこれだけです。

1. 「同一性の候補」区画か、エントリ詳細の「結びついた教材の部品」「結びついた記号」で
   見送り・取り消し済みの行を探します（部品の「深く検討」の「同一性リンク」区画からも同じ操作ができます）。
2. 行の「候補に戻す」を押し、戻す理由を書きます（理由は必須です）。
3. 行は「候補」に戻り、戻した人・日付・前の判断と理由が出ます。前の判断の記録は残ります。
   改めて「確認」で確定するか、「見送り」で見送ります。学生の画面は確定するまで変わりません。

## エントリに別名・隠しラベルを足す {#labels}

**対象タブ:** ナレッジライブラリ / **必要な役割:** 教員以上

1. エントリ一覧から対象のエントリを開きます。
2. 詳細の「別名・隠しラベル」区画で、種類（別名 / 隠しラベル）を選んで語を足します。
   別名は表示にも検索にも使われ、隠しラベルは表記ゆれや読み取りの誤りを検索だけで拾います。
3. 別名の正本はこの区画です。外した語は消えず、「外した」状態で残ります。

## エントリどうしの関係を記録する {#relations}

**対象タブ:** ナレッジライブラリ / **必要な役割:** 教員以上

1. エントリ一覧から対象のエントリを開きます。
2. 詳細の「関係」区画で、相手のエントリを名前で検索して候補から選びます。相手がまだ
   登録されていないときは、その旨が表示されるので、先に「新規エントリ作成」で作ります。
3. 関係の種類（上位・関連・同一・近い）と根拠の種類を選んで記録します。

## 分野の地図との対応を導出・確認する {#atlas-links}

**対象タブ:** ナレッジライブラリ / **必要な役割:** 教員以上

1. 左の一覧から分野を選び、「地図との対応を導出」を押します。分野の地図の概念とエントリを
   突き合わせて対応の候補を作ります（地図そのものは書き換わりません）。
2. 導出の結果（照合した地図の版・候補が見つかった概念・見つからなかった事実）は、ボタンの
   下に事実文で表示されます。
3. エントリの詳細の「分野の地図との対応」区画で、候補ごとに確定または見送りします。
4. まだ凍結していないエントリは、名前・別名の一致だけで照合されます（意味の近さの照合は
   凍結した版で行います）。候補が出ないときは、同じ区画の検索欄で地図の概念を名前で探して
   選び、「対応を付ける」で手で対応を付けられます（候補として入り、確定は同じ一覧で行います）。
