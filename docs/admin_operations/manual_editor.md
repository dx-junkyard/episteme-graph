# マニュアル編集（manual-editor）タブの操作

「マニュアル編集」タブでは、利用者マニュアル（help_kb）の下書き（draft）を編集し、
検証に通ったうえで凍結版として配信に切り替えます。**このタブはシステム管理者
（SYSTEM_ADMIN）のみ**が利用できます。既定の配信ソースはリポジトリ同梱のファイルで、
このタブでの編集は「凍結して配信」を実行するまで学生・教員向けのヘルプ応答には
反映されません。

## マニュアルを編集して凍結配信する {#edit-and-freeze}

**対象タブ:** マニュアル編集（manual-editor） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

1. draft が無い場合は「ファイルから取込」を押します。現在配信中のスナップショットから
   audience（学生 / 教員 / 管理者）ごとの draft を冪等に作成します（既存の draft は
   上書きしません）。
2. 左の一覧からファイルを選び、テキストエリアで編集して「保存」を押します。
3. 保存時に他の編集と衝突した場合（revision が一致しない場合）、自動マージはされません。
   事実文の通知と「再読込」ボタンが表示されるので、最新内容を読み込み直してから編集を
   やり直します。
4. 「凍結して配信」を押すと確認ダイアログが表示されます。確認すると、現在の draft 全体を
   新しい凍結版として作成し、配信ソースを DB（凍結版）に切り替えます。**front-matter・
   見出し anchor・学生向け禁止語彙などの検証（凍結検証）に違反がある場合は凍結が実行され
   ず、違反内容がそのまま一覧表示されます**（要約・捏造はしません）。
5. 配信ソースは「ファイル配信に戻す」「DB配信に切替」ボタンでいつでも切り替えられます
   （いずれも確認ダイアログがあります）。切替自体は既存の凍結版データを削除しません。
6. 「版履歴」に過去の凍結版一覧が表示され、現在配信中の版には「（配信中）」と表示されます。

このタブは自動更新（ポーリング）しません。最新の状態は「更新」ボタンで手動更新して
ください。
