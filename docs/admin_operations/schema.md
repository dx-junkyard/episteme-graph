# DSL進化分析（schema）タブの操作

「DSL進化分析」タブでは、学生のつまづきデータ（未回答クエリ）を分析し、不足している
概念カテゴリ・関係性の拡張を AI が提案します。承認するとシステムのスキーマに反映され、
再抽出ジョブが開始されます。

## DSL進化分析を実行する {#analyze}

**対象タブ:** DSL進化分析（schema） / **必要ロール:** 教員（TEACHER）以上

1. 「DSL進化分析」タブを開きます。
2. 「AIメタ分析を実行」を押すと、未回答クエリの分析から AI が新しい提案を生成します
   （生成に足る未回答クエリが無い場合はその旨のメッセージが表示されます）。
3. 「提案一覧」に表示された各提案について、「承認して適用」または「却下」を選びます。
   **このタブの承認・却下には確認ダイアログがありません**（承認すると即座に新しい
   概念タイプ・述語が登録され、全教材を対象とした再抽出ジョブが開始されます）。
   既存教材への影響をシミュレーション（Shadow Testing）で確認してから慎重に承認したい
   場合は「スキーマ提案」タブを使ってください
   （[スキーマ提案を確認・承認する](schema_proposals.md#review) 参照）。
4. 「提案を更新」を押すと、提案一覧・再抽出ジョブの進捗・現在のスキーマ定義を再取得
   できます。「再抽出ジョブ」欄でジョブの状態（待機中・実行中・完了・失敗）と進捗を
   確認できます。

画面下部の「現在のスキーマ定義」には、概念カテゴリ（OntologyType）と関係性タイプ
（CorePredicate）の一覧が参照専用で表示されます（ビルトインでない拡張分には
「[拡張]」ラベルが付きます）。
