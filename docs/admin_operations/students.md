# 学生管理（students）タブの操作

「学生管理」タブでは、学生アカウントを新規作成し、既存の学生アカウントを一覧・運用します
（一覧・停止・再開などの手順は
[アカウントを一覧する](users.md#list-users) 以降を参照してください）。
教員（TEACHER）以上のロールで利用できます。

## 学生アカウントを作成する {#create-student}

**対象タブ:** 学生管理（students） / **必要ロール:** 教員（TEACHER）以上

1. 「学生管理」タブを開きます。
2. ユーザー名・メールアドレス（任意、未入力時は `ユーザー名@learning.local` が使われます）・
   パスワードを入力し、「学生を作成」を押します。
3. 送信すると即座に作成が実行されます。**確認ダイアログは表示されません**（ユーザー名と
   パスワードの入力必須チェックのみです）。入力内容をよく確認してから送信してください。
4. ユーザー名またはメールアドレスが既に使われている場合はエラーメッセージが表示されます。

作成したアカウントの行は消せません。使わなくなったアカウントは、停止（
[学生アカウントを停止する](users.md#suspend-student)）と、管理者による削除予約（
[アカウントの削除を予約する](users.md#schedule-deletion)）で運用します。削除予約が満了すると
個人データが消去され、アカウントは匿名化されます（行そのものは残ります）。
