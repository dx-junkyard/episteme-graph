# コースの構築・管理

コースは「コース構築」タブで AI と設計し、「コース管理」タブで公開・開示範囲・共有を
管理します。**コースの削除だけは「コース構築」タブ側にあります**
（[コースを削除する](#delete)）。

## AI とコースを設計する {#builder}

**対象タブ:** コース構築（course-builder） / **必要ロール:** 教員（TEACHER）以上

1. 「コース構築」タブを開きます。
2. コースの素材となる教材をカードから選びます（検索・絞り込み・並べ替えができます）。
3. チャット欄に「どんな受講者向けに、何を学べるコースにしたいか」を書いて送信すると、
   AI がコース案（章・トピック構成）を提案します。対話を重ねて調整できます。チャットの
   ヘッダーでこの対話に使う AI モデルを切り替えられます。
4. 納得できたら「承認してコースを登録」を押します。登録すると続けて「リリース前の確認」
   ウィザードが開きます（[リリース前に確認して公開する](#release-review)）。

チャット履歴はセッションとして保存されます。ヘッダーのセッション選択で過去の設計に戻れ、
「+ 新規」で別のセッションを始められます。「既存コースを読込」で登録済みのコースを読み込んで
設計をやり直すこともできます。

## コースの開示範囲を変更する {#visibility}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

コースは 公開（誰でも受講可）/ グループ限定 / 非公開（自分のみ）の開示範囲を持ちます。
対象のコース行の「共有設定」を押し、モーダルの開示範囲を選んで「適用」します。この操作は
後から戻せます。公開にすると、そのコースは公開テンプレートとして学生の受講対象になります。
同じモーダルで、グループごとに `viewer` / `editor` の権限を付与・解除できます。

## コースを学生に公開する {#publish}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

コースを公開すると、公開テンプレートとして学生が受講できるようになります（内部的には
開示範囲を公開にする操作と同じです。「公開する」専用の別 API はありません）。
対象のコース行の状態列にある「公開する」ボタンを押すか、「共有設定」モーダルで開示範囲を
公開にして適用します。**公開は学生の受講対象に直結するため、実行前に確認が入ります。**
公開済みのコースには「公開を止める」が出ます（押すと非公開に戻り、学生の新規受講が
できなくなります。こちらも確認が入ります）。

AI が作った学習マップの割り当てと論文の位置づけを確認しながら公開したいときは、
[リリース前に確認して公開する](#release-review) を使います。

## リリース前に確認して公開する {#release-review}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

対象のコース行の「確認して公開」を押すと、3 ステップのウィザードが開きます（コース構築で
コースを登録した直後にも自動で開きます）。

1. **学習マップの割り当て**: コースのトピックと分野マップの対応を確認し、「この対応で次へ」。
2. **論文の位置づけ**: コースのソース論文の配置を確認し、「この配置で次へ」。個別に直したい
   ものは各行の [却下][再検討] で変更できます。
3. **公開**: 開示範囲を公開にします。

**「次へ」を押すと、表示されている内容を確認したものとして記録されます。** 各ステップには
「あとで」があり、飛ばしても学習者側の表示は変わりません（確認していない配置は学習者にも
「AIによる推定（未確認）」として表示されます）。地図が無い・配置が無い・読み取りに失敗した
場合も、そのまま公開まで進めます。

## コースを削除する {#delete}

**対象タブ:** コース構築（course-builder） / **必要ロール:** 教員（TEACHER。所有者、または
`editor` 権限を持つグループのメンバー）

**コース管理タブにコースの削除ボタンはありません。** 削除は次の手順で行います。

1. 「コース構築」タブを開き、チャット欄の上にある「既存コースを読込」を押します。
2. 一覧から対象のコースの行にある「削除」を押します。
3. 確認ダイアログで**コース名を正確に入力**すると「削除する」が押せるようになります。
   関連する学習履歴も削除されます。

**削除は取り消せません。**

## コースに学習マップ（分野の地図）を割り当てる {#atlas-binding}

**対象タブ:** コース管理（course-management）→ 分野の地図（atlas） / **必要ロール:** 教員
（TEACHER、自分のコースのみ）

コース管理タブの見出し横にある「学習マップ編集」を押すと、「分野の地図」タブの
**「コース配置」区画**へ移動します。

1. 「コースを選択...」で対象のコースを選びます。
2. 「トピックの対応案を作る」を押すと、トピックと骨格概念の対応案が表示されます。この対応案は
   名前などを機械的に突き合わせたもので、AI の生成ではありません。
3. 内容を確認して「この対応で反映」を押すと保存され、学習者側の「分野の地図」にこのコースの
   位置が表示されるようになります（保存するまで学習画面には使われません）。

対応する概念が 1 つも見つからないこともあります。これは異常ではありません。その場合は、
手で対応させる / 後回しにする / 「このコースから新しい分野マップを作る」で分野を起こす、の
いずれかを選べます。骨格が凍結されていない分野では地図を表示できないため、対応する分野の
骨格が公開（凍結）済みであることを確認してください
（[分野の地図の骨格を凍結する](atlas.md#freeze) 参照）。

## 共有ダッシュボードを確認する {#sharing-dashboard}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、閲覧可能なコース）

対象のコース行の「共有ダッシュボード」ボタンを押すと、そのコースの理論コンポーネントに
紐づく説明バージョンごとの、共有・承認・引用の状況が表示されます（個人ごとの追跡ではなく
集計です）。所有者に限らず、閲覧可能なコースであれば owner / editor / viewer のいずれでも
開けます（グループ共有の「共有設定」とは別機能です）。

## コースの共有版を発行・削除予約する {#manage-shared-version}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

対象のコース行の「版の管理」ボタンを押すと共有版（リリース）モーダルが開きます。これは
「共有設定」（開示範囲・グループ共有）とは別機能です。

1. 「共有版として発行」を押すと、その時点のコース内容を不変の版として発行し、共有先へ
   更新通知が届きます。共有先の教員は同意（adopt）するまで自分がピンした版に留まります。
2. 削除予約は猶予期間（既定14日）付きで行え、期限までは「削除予約を取り消す」で取消
   できます。
