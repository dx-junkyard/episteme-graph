# コースの構築・管理

コースは「コース構築」タブで AI と設計し、「コース管理」タブで公開・開示範囲・削除を
管理します。

## AI とコースを設計する {#builder}

**対象タブ:** コース構築（course-builder） / **必要ロール:** 教員（TEACHER）以上

1. 「コース構築」タブを開きます。
2. コースの素材となる教材を選びます。
3. チャット欄に「どんな受講者向けに、何を学べるコースにしたいか」を書いて送信すると、
   AI がコース案（章・トピック構成）を提案します。対話を重ねて調整できます。
4. 納得できたら承認してコースとして登録します。

チャット履歴はセッションとして保存され、後から続きを設計できます。

## コースの開示範囲を変更する {#visibility}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

コースは public（全体）/ group（グループ限定）/ private（自分のみ）の開示範囲を持ちます。
対象のコースを選び、開示範囲を選択して変更します。この操作は後から戻せます。
public にすると、そのコースは公開テンプレートとして学生の受講対象になります。

## コースを学生に公開する {#publish}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

コースを公開すると、公開テンプレートとして学生が受講できるようになります（内部的には
開示範囲を public にする操作と同じです。「公開する」専用の別 API はありません）。
対象のコース行にある「公開する」ボタンを押すか、「共有設定」モーダルで開示範囲を
public にして適用します。**公開は学生の受講対象に直結するため、実行前に確認が入ります。**

## コースを削除する {#delete}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

対象のコースを選び、削除します。**削除は取り消せません。**実行前に確認が入ります。

## コースに学習マップ（分野の地図）を割り当てる {#atlas-binding}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

対象のコースを選び、「学習マップ編集」を開きます。コースのトピックと骨格概念の対応
（binding）を確認・保存すると、学習者側の「分野の地図」にこのコースの位置が表示される
ようになります。骨格が存在しない分野では表示できないため、対応するカートリッジの骨格が
凍結済みであることを確認してください。

## 共有ダッシュボードを確認する {#sharing-dashboard}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、閲覧可能なコース）

対象のコース行の「共有ダッシュボード」ボタンを押すと、そのコースの理論コンポーネントに
紐づく説明バージョンごとの、共有・承認・引用の状況が表示されます（個人ごとの追跡ではなく
集計です）。所有者に限らず、閲覧可能なコースであれば owner / editor / viewer のいずれでも
開けます（グループ共有の「共有設定」とは別機能です）。

## コースの共有版を発行・削除予約する {#manage-shared-version}

**対象タブ:** コース管理（course-management） / **必要ロール:** 教員（TEACHER、自分のコースのみ）

対象のコース行の「版の管理」ボタンを押すと共有版（リリース）モーダルが開きます。これは
「共有設定」（開示範囲・グループ共有）とは別機能です。

1. 「共有版として発行」を押すと、その時点のコース内容を不変の版として発行し、共有先へ
   更新通知が届きます。共有先の教員は同意（adopt）するまで自分がピンした版に留まります。
2. 削除予約は猶予期間（既定14日）付きで行え、期限までは「削除予約を取り消す」で取消
   できます。
