# 分野の地図（atlas）骨格の操作

「分野の地図」タブでは、分野の骨格（スケルトン）を生成・レビュー・凍結できます。
骨格は学習者に「いま学んでいる箇所が分野のどこか」を示すために使われます。

## 骨格を生成する {#generate}

**対象タブ:** 分野の地図（atlas） / **必要ロール:** 教員（TEACHER）以上

対象のカートリッジ（分野）を選び、骨格の生成を実行すると、LLM が骨格 draft を作ります。
凍結する前であれば作り直せます。カートリッジファイルのない新しい分野でも、分野名・説明を
入力して生成できます。

## 骨格を凍結する {#freeze}

**対象タブ:** 分野の地図（atlas） / **必要ロール:** 教員（TEACHER）以上

レビューを終えた骨格 draft を凍結すると、版として確定し、学習者向けの地図に使われます。
**凍結は取り消せません。**実行前に確認が入ります。
