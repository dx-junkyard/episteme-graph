# 分野の地図（atlas）骨格の操作

「分野の地図」タブ（画面上の見出しは「分野マップ」）では、分野の骨格（スケルトン）を作り、
確認し、学習者向けに公開します。骨格は学習者に「いま学んでいる箇所が分野のどこか」を示す
ために使われます。画面は 4 つの区画（分野の選択と状態 / マップ本体 / 修正報告 / コース配置）で
構成され、マップ本体には「1 次版を作る → 2 地図を確認・編集 → 3 報告と影響を確認 →
4 学習者向けに公開」の流れが表示されます。

**AI が作った対応案は学習者には表示されません。**教員が確認し、公開（凍結）した版だけが
学習者に表示されます。公開済みの版は直接変更せず、新しい版として編集します。

## 骨格を生成する {#generate}

**対象タブ:** 分野の地図（atlas） / **必要ロール:** 教員（TEACHER）以上

1. 右上の「分野を選択...」で対象の分野を選びます。まだ無い分野は「新しい分野マップを作る」
   から管理ID・分野名・説明を入れて追加できます（カートリッジのファイルは不要です）。
2. 「次版の編集を始める」を押すと、AI が骨格の次版（下書き）を作ります。編集中の次版が
   すでにある場合は、作り直してよいか確認が入ります。生成に使う AI モデルはボタンの隣の
   チップで切り替えられます。
3. 「地図プレビュー」で内容を確認します。JSON を直接直したいときは「詳細設定（JSON）」、
   一部だけ AI と相談しながら直したいときは「AIと部分修正」を使います（AI が下書きを直接
   確定することはありません。提案を教員が適用して保存します）。
4. 「次版を保存」で下書きを保存します。保存は楽観ロックで、他の教員が先に更新していた場合は
   保存できず、読み直しが必要になります。下書きを捨てたいときは「下書きを破棄」を押します
   （公開済みの版と学習者の表示には影響しません）。

公開する前であれば、この下書きは何度でも作り直せます。廃止（retired）済みの分野では生成・
保存・公開のボタンが無効になります（「復帰する」で戻してから編集します）。

## 骨格を凍結する {#freeze}

**対象タブ:** 分野の地図（atlas） / **必要ロール:** 教員（TEACHER）以上

確認を終えた次版を学習者向けに公開（凍結）すると、版として確定し、学習者向けの地図に
使われます。**公開は取り消せません**（直したい場合は次の版で行います）。

1. 「公開版 (例: 2026.1)」に版数を入力します（未入力では実行できません）。必要なら変更内容の
   メモも入れます。
2. 「公開前チェック」を押します。検証エラーが残っている場合、採用済みでまだ次版に反映して
   いない修正報告・候補がある場合は、そこで止まり、理由が表示されます。
3. この公開で概念が減る・バインド済みコースの対応が外れる場合は、その影響が事前に示されます。
4. 確認画面（公開版・検証エラー / 警告の件数・未確認の修正報告の件数）で「公開する」を押すと
   公開されます。公開すると、その分野の地図を使っているコースの所有者と、骨格を編集した
   ことがある教員に通知が届きます。

追加した項目に既存の論文が並ぶのは、その論文を再解析したときです。

## 修正報告と候補をレビューする {#review-queue}

**対象タブ:** 分野の地図（atlas） / **必要ロール:** 教員（TEACHER）以上

「修正報告のレビュー」区画には、次の 3 つのグループが並びます。いずれも**教員が採用の操作を
するまで骨格には反映されません**（AI やサーバが下書きを書き換えることはありません）。

- **修正報告**: 学習者・教員が地図上から送った記名式の報告です。状態（レビュー待ち / 採用済み /
  見送り / 重複統合）で絞り込めます。採用したら編集中の次版で対応し、公開すると報告者へ
  反映版が通知されます。
- **論文の解析から見つかった候補**: 論文の位置づけで「どこにも置けなかった」主題のうち、
  複数の論文で繰り返し現れたものだけが候補として浮上します。支持している論文はタイトルで
  列挙されます。[採用] / [見送り]（理由の入力が必要です）で判断し、採用したものは
  「下書きへ反映」で次版に取り込みます。見送ったものは「見送り済み」から戻せます。
  候補が既存の概念に近い場合は、注記とともに「別名として登録」できます
  （[ベクトル索引と別名](#vector-aliases)）。
- **関係（辺）の候補**: 概念どうしのつながりの候補です。採用するときに関係の種類
  （隣接 / 依存 / 関連）を選びます。見送りには理由の入力が必要です。採用したものは
  「下書きへ反映」で次版に取り込みます。

いずれも行を消す操作はありません（見送りも記録として残ります）。

## ベクトル索引と別名 {#vector-aliases}

**対象タブ:** 分野の地図（atlas） / **必要ロール:** 教員（TEACHER）以上

マップ本体の区画の下に「ベクトル索引」と「登録済みの別名」があります（公開中の骨格がある
分野でのみ表示されます）。

- **ベクトル索引**: 公開中の骨格の各項目に、論文と同じ空間での索引を作ります。論文を配置する
  ときの候補の絞り込みと、別の表記の検出に使われます。「索引を再構築」で作り直せます
  （公開の直後にも自動で試みます。作れなかった場合でも公開は止まりません）。骨格が更新されて
  いるときはその旨が表示されます。
- **登録済みの別名**: 地図の項目と同じものを指す表記を登録できます。候補のレビューから
  「別名として登録」する経路のほか、この区画で項目の id と表記を入力して「登録」もできます。
  登録した表記は索引と、論文を探すときのキーフレーズに使われます。「見送り」は行を消す操作
  ではなく、同じ表記をもう一度登録すれば戻ります（「見送り済みも表示」で確認できます）。
