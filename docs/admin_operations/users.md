# ユーザー・グループ管理

「グループ管理」タブでは、学生・教員アカウントの作成やグループの管理を行います。
アカウント作成の権限はロールによって異なります。

## 学生アカウントを作成する {#create-student}

**対象タブ:** グループ管理（groups） / **必要ロール:** 教員（TEACHER）以上

学生アカウント作成フォームに必要事項を入力して作成します。**アカウント作成は取り消せません。**
実行前に確認が入ります。

## 教員アカウントを作成する {#create-teacher}

**対象タブ:** グループ管理（groups） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

教員アカウントの作成は **システム管理者のみ** が行えます。教員（TEACHER）の権限では
実行できません。**アカウント作成は取り消せません。**実行前に確認が入ります。
