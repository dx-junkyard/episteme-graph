# グループ管理（groups）タブの操作

「グループ管理」タブでは、教材・コースをグループ内限定で共有するためのグループを
作成・管理します。学生・教員アカウントの作成は別タブに分かれています
（[学生アカウントを作成する](students.md#create-student) /
[教員アカウントを作成する](teachers.md#create-teacher) 参照）。

## グループを作成・招待する {#manage-groups}

**対象タブ:** グループ管理（groups） / **必要ロール:** 教員（TEACHER）以上

- **グループを作成する**: グループ名（説明は任意）を入力して「グループを作成」を押します。
  作成すると招待コードが発行されます。**確認ダイアログはありません。**
- **招待コードで参加する**: 他のユーザーから受け取った招待コードを入力して
  「招待コードで参加」を押すと、そのグループに参加します。
- **招待コードを再発行する**（グループの管理者のみ）: グループ詳細の「再発行」を押すと
  新しい招待コードが発行され、旧コードは無効になります。**確認ダイアログはありません。**
- **ユーザーを直接招待する**（グループの管理者のみ）: ユーザー名を入力して「招待」を押すと、
  相手の「未承諾の招待」一覧に届きます。相手が「承諾」または「辞退」するまでメンバーには
  なりません。
- **メンバーを除名する**（グループの管理者のみ）: メンバー一覧の「除名」を押すと、その場で
  除名されます。**確認ダイアログはありません。**
- **グループを退会する**（管理者以外の自分自身）: 自分の行の「退会」を押すと確認ダイアログの
  あとに退会します。
- **グループを削除する**（グループの管理者のみ）: 「グループを削除」を押すと確認ダイアログの
  あとにグループごと削除します。**この操作は取り消せません。**
