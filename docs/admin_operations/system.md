# システム管理（SYSTEM_ADMIN 専用）

システム統計・エラーログの閲覧は **システム管理者（SYSTEM_ADMIN）のみ** が行えます。

**システム管理者でログインすると、教材管理・コース構築・コース管理・原稿スタジオのタブは
表示されません**（これらは教員のロールで使う画面です）。ログイン直後は「エラー解析」タブが
開きます。

## システム統計を見る {#stats}

**対象タブ:** システム統計（system-stats） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

「システム統計」タブの「全コース・パイプライン統計」で、全コースの解析・原稿生成・音声生成の
進捗と、学生の利用状況（チャンク数・受講者数・チャット数）を一覧できます。教員で絞り込め、
タイトル・アップロード者・日時・チャンク数・受講者数・チャット数の列で並べ替えられます。
「更新」で読み直します。

## エラーログを見る {#error-logs}

**対象タブ:** エラー解析（error-analysis） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

「エラー解析」タブで、システムのエラーログを確認できます。

- 期間（直近1時間 / 6時間 / 24時間 / 7日）で絞り込み、キーワード（セッションID / ユーザーID /
  教材ID / コースID / メッセージ）で検索できます。「INFOを含める」で情報ログも表示します。
- 行を選び、形式（AI解析用Markdown / JSON / プレーンテキスト）を選んで「選択したログを
  コピー」または「表示中すべてをコピー」でクリップボードへコピーできます。
