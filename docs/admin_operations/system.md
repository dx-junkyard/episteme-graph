# システム管理（SYSTEM_ADMIN 専用）

システム統計・エラーログの閲覧は **システム管理者（SYSTEM_ADMIN）のみ** が行えます。

## システム統計を見る {#stats}

**対象タブ:** システム統計（system-stats） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

「システム統計」タブで、教材数・処理状況などの統計を確認できます。

## エラーログを見る {#error-logs}

**対象タブ:** エラー解析（error-analysis） / **必要ロール:** システム管理者（SYSTEM_ADMIN）のみ

「エラー解析」タブで、システムのエラーログを確認できます。
